# 4일 일과 시나리오 (routine_4day)

공부 일과(A)와 밤 일과(B)를 실제로 찍은 영상 4편(A1 → A2 → B1 → B2)으로 기본 논문 방식(FSM 기억)을 시험한다. 실행은 `python -m pam.routine_experiment`(설명은 같은 파일 첫머리).

- 영상: 프로젝트 밖 로컬 폴더 `일과영상_2026-11-04/` (A1·A2·B1·B2.mp4, 공유 안 함). 하루 = 책상 영상 + 불 끄기 영상 + 침대 영상을 이어 붙인 것. B2의 침대 부분은 B1 것을 복사했다.
- `tasks.json`: 로봇 행동 10종. 논문 정형 문장 `Pick up <물건> and place it <장소>.`에 식기세척기 목적지와 `Turn off the <물건>.` 꼴을 더했다. `Pick up the bedside lamp ...`(스탠드 치우기)는 정답 장면이 없는 틀린 선택지다.
- `scenario.json`: 논문 지시문 원본 파일은 그대로 두고, 공간·보관 자리·카메라 한 대·끄기 행동·식기세척기에 해당하는 문장만 바꿔 넣는다. 바꾼 이유는 각 항목의 `reason`에 있다.
- 첫날(A1)에는 기억이 없다(`memory_files`가 비어 있음). 하루 끝 자기반성으로 규칙을 처음 만든다.
- 정답(1초마다)은 평가자 전용이라 이 폴더에 두지 않는다: `experiments/routine_2026-11-04/정답/` (모델 입력에 넣지 않음).
