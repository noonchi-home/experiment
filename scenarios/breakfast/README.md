# 현재 실험: 식탁에서 시작하는 아침 식사

현재 실행에는 `scenarios/breakfast/scenario.json`을 사용합니다. 과거 `scenarios/morning`은 2026-10-24 실험의 재현을 위한 보존 설정입니다.

FSM(활동 단계와 전이로 표현한 기억)은 **식사 준비 → 식사 중 → 식사 종료 → 외출 후**의 네 상태입니다. 우유 조건은 **식탁 착석 + 곁에 우유 없음 + 우유를 잡거나 만지지 않음**입니다. 컵·접시는 식사 종료, 일부 정리, 실제 출입구를 통한 외출이 관찰된 경우에 정리합니다. 한 번에 한 행동 또는 대기를 선택합니다.

초기 기억은 사람이 작성한 가정입니다. 과거 VLM 반성 결과의 착석 조건과 같은 문구를 사용하지만, 이 네 상태 초기 기억 전체가 모델의 원본 출력이라고 주장하지 않습니다. 원본 모델 응답과 과거 기록은 변경하지 않습니다.

`initial_list.json`은 같은 도움 규칙을 상태 구분 없이 나열한 비교용 기억입니다. 원문 프롬프트는 보존하고 환경·목적지만 `scenario.json`에 기록한 문자열 치환으로 바꿉니다. VLM이 기억 전체와 사진을 읽으며, 코드가 현재 상태나 행동을 대신 선택하지 않습니다.
