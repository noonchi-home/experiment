# 매초 사진 분석 결과

직접 촬영한 영상에서 추출한 사진을 보고 모델이 매초 내놓은 장면 설명, 판단 이유, 선택 행동입니다. 아래 4개 파일은 상태별 도움 규칙을 기억하는 FSM 조건의 실행 기록이며, 첫날에는 이전에 배운 규칙이 없어 기억 없이 판단했습니다. 목록 형태의 규칙을 기억하는 조건과 별도로 진행한 기억 없음 조건의 기록은 포함하지 않습니다.

| 촬영 영상 | 분석 결과 | 결과 수 | 판단할 때 참고한 규칙 |
|---|---|---:|---|
| 공부 첫날 | [공부_첫날.jsonl](공부_첫날.jsonl) | 202 | 이전 규칙 없음 |
| 공부 둘째 날 | [공부_둘째날.jsonl](공부_둘째날.jsonl) | 215 | [공부 첫날 뒤 만든 상태별 규칙](../기억/fsm_A1뒤.json) |
| 밤 일과 첫날 | [밤일과_첫날.jsonl](밤일과_첫날.jsonl) | 169 | [공부 둘째 날 뒤 수정한 상태별 규칙](../기억/fsm_A2뒤.json) |
| 밤 일과 둘째 날 | [밤일과_둘째날.jsonl](밤일과_둘째날.jsonl) | 182 | [밤 일과 첫날 뒤 수정한 상태별 규칙](../기억/fsm_B1뒤.json) |

각 파일은 한 줄에 JSON 하나를 저장하는 JSONL 형식입니다.

| 항목 | 뜻 |
|---|---|
| `t` | 영상 시작부터 지난 시간(초) |
| `status` | 응답 형식 검사 결과. `valid`는 필요한 형식을 갖췄다는 뜻이며, 판단 내용의 정답 여부를 뜻하지 않음 |
| `observation` | 사진을 보고 모델이 설명한 장면. 실제 장면과 다르게 인식한 내용도 원문 그대로 포함 |
| `reasoning` | 모델이 밝힌 행동 선택 이유 |
| `task_index` | [행동 목록](../../scenarios/routine/tasks.json)에서 선택한 행동의 순서 번호(0부터 시작). `0`은 컵을 사람 옆에 가져다주기, `-1`은 아무것도 하지 않음 |
| `errors` | 응답 형식 검사에서 발견된 오류 |

각 시점의 판단에는 그 시점까지 최근 사진을 최대 9장 사용했습니다. 기록은 모델의 판단 결과이며, 로봇이 실제로 행동을 실행했다는 뜻은 아닙니다. 기존 실행의 원본 `predictions.jsonl` 파일을 이름만 바꿔 복사했으며 내용은 수정하지 않았습니다.
