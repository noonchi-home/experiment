# 아침 생활 상황

이 폴더는 PAM 논문의 판단 방법에 넣을 생활 환경과 기존 습관을 정의한다. 논문 원문 지시문은 `prompts/paper/`에 그대로 두고, 이 상황에서 필요한 문장만 `scenario.json`의 정확한 문자열 치환 목록으로 바꾼다.

`initial_fsm.json`은 생활 단계를 구분한 초기 기억이다. 침대에 있음 → 아침 시작 → 식사 중 → 식사 종료 → 외출의 다섯 단계를 담는다. `initial_list.json`은 같은 세 행동 규칙을 단계 구분 없이 담은 초기 기억이다. 둘 다 사람이 작성한 가정이며, 실제 여러 날을 관찰해 모델이 학습한 결과가 아니다. 사용자가 말한 약 5일차는 이미 습관이 있다는 뜻으로 적용했고, 관찰한 날짜 수를 꾸며 기록하지 않았다.

| 행동 번호 | 표시할 행동 | 기억에 담은 상황 |
|---|---|---|
| 0 | 우유를 사용자 곁에 가져다놓기 | 아침에 깨어 침대에서 일어나고, 우유는 아직 보관 위치에 있음. 다른 음식이 달라도 우유를 마시는 습관을 참고함. |
| 1 | 컵을 싱크대에 가져다놓기 | 식사가 끝나 일부를 치운 뒤 실제 외출한 모습이 관찰되고, 사용한 컵이 식탁에 남아 있음. |
| 2 | 접시를 싱크대에 가져다놓기 | 같은 정리 상황에서 사용한 접시가 식탁에 남아 있음. |
| -1 | 지금은 아무 행동도 하지 않기 | 원문처럼 현재 사진과 기억으로 즉시 할 적절한 행동을 고르지 못함. |

행동 번호는 출력 문장을 찾는 인덱스이며 실행 우선순위가 아니다. 컵과 접시가 모두 정리 가능한 장면에서는 둘 중 하나를 선택해도 적절할 수 있다. 한 번의 판단에서는 한 물체에 대한 행동 하나만 선택한다. 사진에 사람이 없다는 이유만으로 외출했다거나 깜빡했다고 단정하지 않는다. 정리 규칙은 식사 종료, 일부 정리, 실제 출입구를 통한 외출을 뒷받침하는 관찰을 요구한다.

모델이 행동 문장을 출력해도 실제로 물건을 옮긴 것은 아니다. 다음 사진이 달라졌다고 자동 가정하거나 이미 행동을 끝냈다고 기억에 기록하지 않는다. 초기 기억의 조건이 사진에 보이지 않으면 부족한 근거를 그대로 드러내야 한다.

`scenario.json`은 공간·물체·표면·목적지와 기억 출처 표현만 바꾼다. 판단 출력 형식, 상태별 기억을 전체적으로 참고하는 원칙, 기억 생성·하루 말 갱신 지시문은 유지한다. 코드가 상태를 순서대로 강제하거나 손으로 만든 규칙으로 모델의 행동 선택을 대신하지 않는다. 기억 생성 기능은 이번에 이미 습관이 있다는 시작 가정 때문에 호출하지 않는 것이며, 이후 관찰에서 기억을 생성·갱신하는 기능은 계속 사용할 수 있다.

파일별 출처와 가정은 `provenance.json`, 원문 변경 목록은 `docs/아침상황_원문변경표.md`에서 확인한다. `tests/test_morning_scenario.py`는 파일 형식과 원문 변경 범위를 확인하는 오프라인 시험이다. 이 시험의 통과는 사진을 본 모델이 올바른 행동을 골랐다는 결과가 아니다.
