## 예상 규칙을 해석할 때

- **세탁물 꺼내기**는 이번 회차의 세탁 완료가 선행해야 하는 기기 관계입니다. 10월 14일 밤 처음 확인했습니다. 세탁물을 어디에 말릴지는 별도의 선택입니다. 빨래를 꺼낸 8회 중 비가 온 4회 모두 건조기로 옮겼지만 우연 확률을 검사한 값이 0.0625라서 채택 기준 0.001 미만을 통과하지 못했습니다.
- **스포츠 채널과 맥주**는 사람의 TV 채널 선택 전체에서 검사합니다. 11월 4일 밤 채널 37 조건 안에서 4/4가 일치했고, 전체 기본 비율은 5/29였습니다. 단측 검정값이 약 0.000884여서 이날 처음 통과했습니다. 수요일인 이날에는 다른 채널에서 맥주를 가져오지 않은 기회가 더해졌습니다. 앞선 10월 30일에는 저녁 식사 도중 드라마에서 경기로 바꿨는데, 60분 안에 이어진 채널 선택이어서 첫 채널을 대표로 사용했습니다.
- **조건이 우연히 맞는 경우**도 있습니다. 마지막 밤에는 평일 21시대 TV를 켜는 조건도 맥주 규칙의 기준을 통과합니다. 이번 자료에서 점수가 나온 조건이며 새로운 날짜에서도 이 사람의 선호를 설명하는지는 따로 확인해야 합니다.
- **약통과 이불**은 사람이 한 일을 따로 봅니다. 물컵을 준비하는 규칙과 약을 실제로 복용했는지는 다릅니다. 반복해서 이불을 갰어도 이불을 접을 장치와 작업이 확인되지 않아 사람의 행동만 기록합니다.

## 학습과 실행 판단의 기준

같은 시작 사건은 첫 시각부터 60분 동안 한 기회로 묶습니다. 자연행동이 30분 안에 시작했는지를 보고, 이미 한 일과 관찰 불가는 비율에서 뺍니다. 가전 신호를 완전히 기록한 자료에서 필수 신호가 없는 경우도 행동 부재의 근거가 됩니다. 습관 채택에는 서로 다른 4일 이상, 확인된 기회 중 80% 이상이 필요합니다. 조건을 더 붙이면 전체보다 20%p 이상 높고 단측 이항검정 p<0.001이어야 합니다. 한 조건을 먼저, 두 조건 조합을 다음에 검사합니다. 시각 후보는 전체 행동 중 서로 다른 날이 가장 많이 들어오는 30분 구간에서 가장 이른 시작을 선택하고, 가전 사건 규칙이 미달한 후보에서 날짜별로 다시 검사합니다.

이번 채점은 지정한 후보 목록에 대해 고정했습니다. 공통 조건은 요일·날짜 종류·한 시간 단위 시간대·로봇의 관찰 위치·비 여부·전원이 켜진 뒤 확인한 TV 채널·최근 30분 내 확인한 방문객·2도 폭 실내온도입니다. 정의하지 않은 코스, 재고 센서값, 복용 결과는 추정하지 않습니다. 각 날짜에서 같은 시각대의 이미 한 일을 찾는 시각 후보 계산은 앞선 90분 이내 관찰을 사용합니다. 자연 관찰 재생에서 이미 채택한 규칙은 새로 충족한 근거가 있으면 갱신하며, 조건을 지우는 사용자 반응이 관찰되기 전까지 유지합니다. 미확정 행동의 시험 실행은 별도로 승인된 목록이 없어 채점하지 않습니다.

실행은 필요한 확인을 마쳐 명령을 시작한다는 뜻입니다. 대기는 안전·재고·대상 상태에 확인할 점이 있는 경우, 취소는 사람이 이미 시작했거나 대상 작업이 필요 없어졌을 때입니다. 미개입은 해당 시각에 새 규칙을 시작할 근거가 없는 경우입니다. 처음부터 적용하는 안전 조건은 개인이 배운 습관 수에서 뺐습니다. 이 집에서 빠짐없이 이어진 가전 신호는 전날의 마지막 상태도 사용합니다. 화면에서 사라진 이동 가능한 물건의 현재 위치는 따로 확인합니다.

## 실제 결과 파일과 대조하기

Python 3를 사용할 수 있는 환경에서 정답지 폴더를 열고 아래처럼 실행하세요. 밤에는 당일 학습을 마친 활성 규칙 전체, 낮에는 그날의 판단을 제출합니다. 파일은 UTF-8이고 한 줄에 JSON 객체 하나를 씁니다. 날짜 하나만 볼 때는 --날짜를 붙입니다.

```powershell
python 결과대조.py --밤 실제밤.jsonl --낮 실제낮.jsonl --날짜 2026-10-25 --출력 차이.json
python 결과대조.py --낮 실제명령.jsonl --명령만 --출력 명령차이.json
```

밤 입력 형식의 예입니다. 아래 빈 배열은 그날의 **전체 학습 규칙이 0개**라는 뜻입니다. 고정 안전 조건은 밤 제출 대상에서 제외합니다.

```json
{"날짜":"2026-10-12","규칙들":[]}
```

학습한 사건 규칙 하나는 `{"규칙ID":"am_water","경로":"사건","조건":{}}` 형태로 배열에 넣습니다. 시각 규칙에는 `"시각":"HH:MM:SS"`도 포함합니다. 규칙 식별자와 한국어 이름은 [규칙 목록](규칙목록.md)에 있습니다.

낮 입력 형식 예시입니다.

```json
{"날짜":"2026-10-25","시각":"12:29:36","행동":"문이 열려 있고 앞이 비면 냉장고 문 닫기","판정":"실행"}
```

비교 도구는 날짜·4초 눈금의 정확한 시각·행동명으로 비교합니다. 실제 장치의 완료 시각 대신 판단을 내린 시각을 넣으세요. 명령만 비교하는 날에 명령이 0건이면 `{"날짜":"2026-10-13","실행기록완료":true}`처럼 재생 완료를 표시합니다. 다른 이름이나 같은 효과의 별도 규칙은 먼저 대응시키거나 차이 보고서에서 따로 검토하세요.

채점자료/밤별규칙.jsonl은 밤별 근거와 조건 검사를, 시각별판단.jsonl은 그때의 판단과 사후 자연행동 대조를 담습니다. 원본근거와기회.jsonl에는 묶기 전 522개 사례의 원문과 줄 번호가 있습니다. 전체신호색인.jsonl은 861건의 가전 신호를 모두 찾을 수 있는 목록입니다. 단순 상태 보고 등 직접 채점 항목이 없는 신호도 포함합니다. 점수는 정의한 판단 지점의 일치도를 뜻합니다. 매 4초의 모든 가능한 행동이나 다른 방식의 규칙 표현까지 유일하게 정답이라고 가정하지 않습니다.
