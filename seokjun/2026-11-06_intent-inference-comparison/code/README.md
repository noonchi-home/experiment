# 사용자 의도 비교 실험 실행 방법

[실험 결과와 채점표](../README.md) · [보관한 원자료](../data/)

11개 Python 파일은 당시 실행에 사용한 사본이다. Python 3 표준 라이브러리를 쓴다. 보관된 결과는 링크에서 바로 열 수 있다. 아래 명령은 새로 모델을 호출해 비용이 발생한다. 실행 서비스에서 해당 모델을 제공해야 한다.

## 15개 장면 비교

이 안내 문서가 있는 code 폴더에서 실행한다. OpenAI 인증키는 실행 환경의 OPENAI_API_KEY로 읽는다. 각 명령은 독립적으로 실행할 수 있다.

~~~powershell
python -X utf8 direct_ask.py
python -X utf8 fsm_test.py
python -X utf8 ip_run.py
~~~

차례대로 줄글로 묻기, 관찰을 상태 변화로 바꾸어 묻기, 역계획 기본·경고 설정을 실행한다. 각 결과는 코드 옆에 direct_ask_raw.json, fsm_test_raw.json, ip_run_raw.json으로 저장된다. 앞의 두 명령은 이전 실행 결과를 덮어쓰고, 역계획은 기존 결과에 든 장면을 건너뛴다. 매번 처음부터 비교하려면 11개 Python 파일만 새 폴더에 복사한 뒤 그곳에서 실행한다. 게시용 원자료는 같은 실험 폴더의 data 폴더에 별도로 보관한다.

## 장면과 예비 시험

- ip_scenes.py에 장면별 영어 관찰, 로봇 행동 규칙, 한국어 정답이 있다. 한국어 정답은 결과 대조에 쓰인다.
- logprob_check.py는 모델이 답변 후보의 출력 확률을 반환하는지 확인하는 초기 점검이다.
- logprob_reliability.py, logprob_reliability2.py, yesno_test.py는 선택지 순서와 반복에 따라 점수가 달라지는지 확인한다.
- verbal_score_test.py, scoring_methods_test.py, ga_warn_test.py는 숫자로 답하기, 숫자의 출력 확률을 이용한 가중 평균, 과신 경고의 효과를 확인한다.

예비 시험도 같은 폴더에서 해당 Python 파일을 개별 실행한다. OpenAI와 DeepSeek를 함께 시험하는 파일은 DEEPSEEK_API_KEY도 사용한다. 역계획 실행 비용은 당시 코드에 적힌 단가로 계산했으며, 재실행 금액은 서비스 단가와 응답 길이에 따라 달라진다.

## 후보 점수는 어떻게 정했나

처음에는 ‘가능하다 / 가능하지 않다’를 고르게 했다. 보기 순서에 따라 결과가 달라지거나 점수가 양끝에 몰렸다. 숫자로 답하게 해도 5점 단위 동점이 생겨, 모델이 출력할 수 있었던 숫자에 각각의 출력 확률을 곱해 평균을 내는 방법을 시험했다.

<details>
<summary>점수를 정하기까지의 예비 시험 6개와 원자료 펼치기</summary>

한 예로 ‘사용자는 나중에 마시고 싶다’와 ‘사용자는 음료를 원하지 않는다’는 모두 ‘컵을 옆으로 치웠다’는 행동을 설명할 수 있다. 이런 후보들을 가르기 위해 의도와 행동의 짧은 조합 8개에서 다음 방법을 시험했다. ‘높게 나와야 한다’ 또는 ‘낮게 나와야 한다’는 기대도 Claude가 정했다.

| 예비 시험 | 관찰과 다음 선택 | 원자료 |
|---|---|---|
| ‘가능함 / 가능하지 않음’을 A·B 중 고르게 함 | 일부 모델은 보기 순서를 바꾸자 점수가 크게 달라졌다. | [보기 순서와 반복 결과](../data/logprob_reliability_raw.json) |
| 다른 모델에서 A·B 방식과 내용 없는 선택을 비교 | gpt-6-sol과 gpt-6.1-terra의 결과는 모델당 48번 모두 0 또는 1로 집계됐다. | [모델별 추가 시험](../data/logprob_reliability2_raw.json) |
| 예·아니오로 답하게 함 | gpt-6.1-terra는 기대한 방향을 맞혔지만 48번 모두 양끝값이어서 후보 간 점수 차이를 표현하기 어려웠다. | [예·아니오 결과](../data/yesno_raw.json) |
| 0~100 사이의 수를 말하게 함 | 점수가 5~95로 퍼졌지만 모두 5의 배수여서 동점이 생겼다. | [숫자 응답](../data/verbal_score_raw.json) |
| 모델이 답으로 낼 수 있던 숫자들을 각각의 출력 확률로 가중 평균 | 컵을 치우는 행동에서 ‘나중에 마실 수도 있다’와 ‘원하지 않는다’가 90점 동점에서 평균 90.6점과 86.8점으로 갈렸다. 경고와 양쪽 이유를 함께 요청한 방식도 비교했다. | [숫자 가중 평균과 이유 설명](../data/scoring_methods_raw.json) |
| 숫자 가중 평균에 과신 경고 한 줄을 추가 | 같은 두 후보는 평균 81.3점과 74.7점이었다. 경고의 영향을 보려고 15개 장면에서 기본·경고 설정을 함께 실행했다. | [경고 추가 결과](../data/ga_warn_raw.json) |

</details>

실제 15개 장면에서는 점수가 가장 높은 후보도 기준에 못 미치면 후보를 더 만들도록 했다. 기준은 기본 설정 30점, 과신 경고를 붙인 설정 40점이었다. 후보를 더 만든 장면은 0개였고, 두 설정의 1위 문장이 같았던 장면은 11개였다. 두 설정을 합친 실행 기록은 호출 1,107회, 오류 0회, 5분 24초다. [실행 로그](../data/ip_run_out.txt)
