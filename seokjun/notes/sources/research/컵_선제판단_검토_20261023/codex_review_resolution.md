# Claude 검토 반영과 Codex 확인

검토 대상: candidate.md. 사용자 # 지시에 따라 ai-meeting으로 실제 Claude Opus 5.5 / XHigh를 호출했다. 실제 답변은 revise(일부 수정 필요)였으며, 원문은 claude_review.md에 보존한다. Claude는 제공 자료를 검토했고 외부 논문을 직접 열람하지 않았다. Codex가 웹 원문과 공식 코드를 확인했다.

## 수용하고 수정한 부분

1. ICL 설명의 잘못된 문장을 수정했다. ContextAgent에서 ICL은 비교군이며 SFT 주 제안과 구분한다. 확인한 API 비교군의 점수 검사 부재와 척도 차이도 명시했다. 이는 고정 커밋의 특정 경로를 읽은 결과이며 전체 구현에 같은 주장을 일반화하지 않는다.
2. Proactive Physical AI 표1을 다시 확인했다. 같은 Worker와 예산 비교의 role F1 28.72→33.45%, FP/min0.62→0.18을 함께 제시했다. 다만 Claude의 '오개입' 표현은 수정했다. 원문 부록D.1은 정답창과 대응되지 않은 응답을 모두 실제로 해로운 도움이라고 해석할 수 없다고 명시한다.
3. Patel 논문의 HOMER가 합성 데이터이며 가구별50일학습/10일시험이라는 점과 식후 그릇 정리 시연을 추가했다. 공식 PMLR 페이지의 PDF 링크와 arXiv §7.4·8을 직접 확인했다.
4. PAM이 있을 때 사용자 피드백을 기억 갱신에 사용한다는 점을 추가했다. 추가관찰에 대해서는 '평가한 행동 목록에 포함되지 않았고 선택정책을 검증하지 않았다'로 범위를 한정했다.
5. 모델 확신을 기록하는 것과 검증된 확률로 사용하는 것을 구분했다. 관측 품질·근거 충분성은 먼저 기록하고, 수치 확률을 사용할 경우 목표를 정의하고 별도 보정 검증을 하도록 명시했다.
6. 기억 예시에 재사용한 반례와 관측 기간을 넣었다. 과거 빈도는 현재 사용 종료 확률과 같지 않다. 사람이 나간 직후 사례에서 기다림도 가능하다고 명시했다.
7. 합성 생성기·평가기 편향, 반복 실행, 행동에 따라 달라져야 하는 후속 상태, 관측 예산을 설명했다.

## 그대로 채택하지 않은 해석

- '검증 데이터로 충분성을 평가한다'가 반드시 '수치 비용표/확률 기준값으로 결정한다'를 뜻하지는 않는다. 분류 모델 직접 선택도 별도 데이터로 평가할 수 있다. 따라서 초안의 비용표 비필수 입장을 철회하지 않고, 두 설계를 비교 가능한 선택지로 명확히 했다.
- Claude의 확신 기록 제안은 수용했지만, 모델의 자기보고 수치를 필수 실행 기준으로 만들지는 않았다.
- Horvitz(1999)는 Microsoft Research 원문을 확인해 보조 이론으로 추가했다. 사용자에게 질문하는 선택을 자동 관찰로 바꾸는 것은 원 논문이 컵에서 검증한 결과가 아니라 우리 적용이다. 최신 물리적 proactive 논문을 중심에 두고 이 고전을 주 해결책처럼 제시하지 않았다.
- 규칙 기반 합성 생성도 생성 규칙의 편향이 있으므로, 규칙에서 나온 숨은 의도만으로 유일 행동 정답을 강제하지 않는다. 관측으로 구분 가능한지와 라벨의 적절성을 따로 확인한다.

## 미확인·미실행

- DeepSeek 컵 실험, 로컬 모델 실행, 학습, 로봇 실행은 하지 않았다. 문서의 입출력은 설명용 예시다.
- PAM의 CoRL2026 표기는 저자 페이지와 arXiv에서 확인했으나 별도 공식 학회 목록은 확보하지 못했다. 수상·독립 재현을 확인한 것으로 표시하지 않는다.
- 최종 문서는 검토 후 수정한 Codex 결과이며, 동일 파일을 Claude가 재승인한 문서는 아니다. 최종 구조 선택은 미확정이다.
