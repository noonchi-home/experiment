# 컵 선제 판단 연구 검토 종료 기록

## 사용자 목표와 범위

명령 없이 집 안에서 선제적으로 판단하는 AI를 연구하며 첫 합성 실험은 컵을 치울지 결정하는 것이다. 이번 턴은 원문 조사와 설계 설명이다. 실제 DeepSeek 실험이나 학습은 범위에 없다.

## 실제 검토

Claude Opus5.5, 명시적 --effort xhigh, 새 검토 문맥으로 사용자 원문·조건·Codex초안·출처메모를 전달했다. 응답 verdict=revise. Claude의 원문 열람이나 실제 실험은 없으며 Codex가 외부 원자료를 확인했다.

## 반영한 사항

ContextAgent의 ICL비교군 표현, 논문과 API코드의 실행조건 차이, ProAgent 동일예산 성능비교 및 지표해석, HOMER합성자료, PAM피드백, 확신의 기록과 보정 구분, 모호한 사례의 대기 선택과 데이터편향을 수정했다. Horvitz1999는 원문을 확인한 후 보조이론으로만 추가했다.

## Codex 판단과 남은 실험

검증 데이터를 사용한다고 수치 비용표가 필수인 것은 아니다. 모델 직접 선택을 우선 평가하고 기준값 기반 설계는 비교 가능한 가설로 둔다. 이는 양 모델의 재검토 합의로 표시하지 않는다.

현재상태/시간이력/활동기억/선택관찰의 효과, 컵 사용 종료 라벨, 관측도구 비용과 대기 예산, 로컬 모델 학습 여부는 실제 실험으로 검증할 대상이다. 구현·학습은 미실행이며 구조는 확정하지 않았다.
