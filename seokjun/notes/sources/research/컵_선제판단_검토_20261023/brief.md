# 현재 상태: 가스 밸브·불꽃·화구 온도, 창문, 청소기, 가스·일산화탄소·연기 농도, 방별 먼지, 비 감지
시간 흐름: 켜져 있던 시간(가스 42분), 변화 추세(냄비 온도 상승), 사람이 마지막으로 감지된 시각
사람: 방별 재실 여부, 추정 활동(요리·수면·외출), 아이·노인 여부, 평소 생활 패턴
외부: 일기예보, 바깥 미세먼지, 시각
기기 행동: 가능한 행동, 부작용, 실행 조건(예: 누가 자고 있을 때 소음)
가정 정책: 설치할 때 한 번 정함(예: 가스는 경고 우선)
물체 기억 (컵 예시): 물체별로 무슨 일이 있었는지 기록
이런 입력데이터를 어떻게 해석할건데?

0층 안전 규칙 (코드): 가스·연기 농도가 기준을 넘으면 즉시 차단합니다. LLM이 뒤집을 수 없고, API 응답이 늦어도 작동합니다.
1층 해석 (LLM): 보이지 않는 상태를 추정하고 근거와 확신 정도를 적습니다.
2층 제안 (LLM): 후보 행동마다 기대 효과, 틀렸을 때의 피해, 되돌릴 수 있는지를 적습니다.
3층 승인 (코드): 피해 비용표와 규칙으로 최종 행동을 고릅니다.
4층 피드백: 사용자가 되돌린 행동(예: AI가 끈 가스를 다시 켬)을 오판 기록으로 저장합니다

# 필요한 기존 조건

- 사용자의 목표는 매번 명령받지 않고 집 안 상황에서 도움 필요성을 스스로 판단하는 proactive AI다. 사용자에게 받는 정보와 질문은 거의 없어야 한다.
- 첫 실험 대상은 컵을 치울지 판단하는 일이며 모든 입력은 합성데이터다.
- 현재 DeepSeek API로 실험하고, 이후 로컬 Qwen 등과 학습/모델수정을 검토할 생각이다. 현재 모델이나 구조가 확정된 것은 아니다.
- 행동을 결정하기 위해 정보가 부족하면 어떤 추가 정보를 얻을지 모델이 결정할 수 있기를 원한다. 사용자 원래 예: 컵 안에 내용물이 있는지 확인.
- 사용자는 유명하고 검증된 행동결정 연구에서 구체적인 아이디어를 얻고 싶어한다. 이번 요청은 조사·설명이며 실제 로봇 제어·API 실험·학습 실행 요청은 아니다.
- 기준일은 2026-10-23이다.

# 이번 검토 범위

별도 candidate로 전달된 Codex 답변 원문을 위 요구와 첨부 원자료에 비추어 검토한다. 새 검토 문맥이며 이전 모델들의 의견이나 동의는 제공하지 않는다. 자료에 없는 실험을 실행한 것으로 간주하지 않는다.
