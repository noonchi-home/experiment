**처음에는 추가 학습 없이 로컬 모델을 시험한다는 뜻은 맞아. 하지만 최종적으로도 학습하지 않기로 정한 것은 아니야.** 추가 학습 전 성능을 기준으로 확보하고, 우리 과제에 필요한 학습의 효과를 비교하자는 뜻이야.

Qwen 같은 모델 중에는 이미 사전학습과 지시 학습 등을 거쳐 질문에 답할 수 있게 공개된 모델이 있어. 이런 모델은 다운로드해서 바로 추론에 쓸 수 있어. 다만 ‘실행할 수 있다’와 ‘우리 집안 의사결정을 충분히 잘한다’는 다른 문제라 실제로 시험해야 해.

우리 작업은 두 가지로 나누어 생각하면 돼.

| 작업 | 하는 일 | 모델의 학습된 파라미터를 바꾸나? |
| --- | --- | --- |
| 입력·기억·도구·판단 절차 설계 | 시간 이력과 현재 상태를 주고, 필요한 정보를 조회하고, 행동 결과를 다시 받게 함 | 보통 아니야 |
| 추가 학습·파인튜닝 | 검토된 사례를 학습시켜 상황 해석, 관측 선택, 행동·대기 선택을 우리 과제에 맞게 조정 | 응. LoRA라면 보통 원래 가중치는 고정하고 작은 추가 파라미터를 학습해 |

**학습시킨다면 단순히 답변 형식만 가르치는 것이 아니라, 네가 중요하게 보는 행동 의사결정도 학습 대상으로 삼을 수 있어.** 예를 들어 시간 이력과 현재 관찰을 보고 어떤 정보가 더 필요한지 선택하고, 그 관측 결과에 따라 행동하거나 기다리는 사례를 학습시키는 거야. 성능이 실제로 좋아지는지는 따로 확인해야 해.

내 제안은 지금부터 추가 학습 가능성을 고려해 데이터를 준비하는 거야.

1. DeepSeek API로 합성 상황의 판단 흐름을 시험하고, 관찰·선택한 도구·도구 결과·행동·성공과 실패를 기록한다.
2. API 답을 정답으로 그대로 쓰지 않고, 검토·교정한 기록을 학습 후보로 모은다.
3. 로컬 모델 후보도 추가 학습 전 상태로 같은 과제에서 평가한다. DeepSeek에서 잘됐다고 작은 로컬 모델도 잘한다고 가정하지 않는다.
4. 정보는 충분한데 판단·관측 선택이 반복해서 틀리고, 교정 데이터가 준비되면 미세조정한 모델과 비교한다. 학습에 쓰지 않은 상황에서도 개선되는지 확인한다.

반대로 사람의 재실 여부 같은 정보 자체가 없어서 구별하지 못하는 문제라면, 학습만으로 실제 정답을 알아낼 수는 없어. 그때는 관측 도구와 입력 구성을 먼저 보완해야 해. 충분히 잘하는 모델이라면 추가 학습 없이 사용할 가능성도 열어 두고 있어.

따라서 현재 제안은 **‘학습을 안 한다’가 아니라, 학습 전후를 비교할 수 있게 만들고 근거를 보고 우리 판단 방식에 맞춘 추가 학습을 결정하자**는 거야.
