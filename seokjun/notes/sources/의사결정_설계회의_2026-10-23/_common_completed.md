# 공통 회의 상태

## 사용자 목표

사용자 입력을 최소화하는 선제적 가정 AI의 관찰·판단·행동 구조를 검토한다. 최초 실험은 합성 데이터와 DeepSeek API이며 이후 로컬 Qwen 등을 고려한다. 지금 최종 구조나 모델을 확정하지 않는다. 독립 의견을 먼저 받고 실제 피드백을 교환하여 수정된 두 의견을 보고한다.

## 수행 완료

- Codex 독립 초안을 먼저 보존했다.
- Claude Opus 5.5, CLI --effort max를 지정했다. 001은 600초 시간 초과. 002 독립 의견, 003 교차 검토·수정 의견, 004 관측 기준 보완을 실제로 받았다.
- 최초 성공 호출에는 Codex 의견과 자료가 없었다. 도구·기존 설정 로딩을 제한하고 별도 문맥으로 실행했다.
- Codex는 원문과 반례로 검토했고 Claude의 지적을 반영한 별도 의견서를 작성했다.

## 양측의 현재 의견에서 확인되는 공통 부분

부분 관찰과 시간 이력, 관측의 가치, 상태·활동·목표·정책의 구분, 주어진 기기 사양과 모델 밖의 실행 검사, 결과 피드백이 중요하다. 여러 에이전트와 파인튜닝은 실패 원인과 비교 실험을 보고 결정한다. 근거 없는 모델 확률을 코드로 계산한다고 신뢰성이 생기지 않는다. 사용자 되돌리기는 즉시 오판 레이블이 아니다. 고정된 관측 비용 순서와 모델의 분기 계획만으로 관측 가치 자동 판정은 채택하지 않는다.

## 진행자 판단과 남은 차이

Codex는 Claude 004의 ‘같은 계획이면 자기모순 자동 판정’이라는 표현을 그대로 채택하지 않는다. 추가 검토 표시로만 쓰고 사전 주장·판단 기간·실제 결과를 확인해야 한다. 계획과 다른 행동도 정당한 재계획인지 구분해야 한다. 전체 최종 보고서는 별도 재승인받지 않았으므로 공동 승인문으로 표시하지 않는다.

## 미확정·미실행

장치별 실제 동작, 비용·목표·허용 수준, 데이터·평가 규모, 최종 모델·에이전트 수·학습 여부는 미확정이다. DeepSeek API 실험, 로컬 모델 학습, 실제 기기 제어는 하지 않았다. 이 미확정은 회의 결과이며 독립 의견·피드백 절차의 미수행을 뜻하지 않는다.
