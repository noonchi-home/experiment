# 사용자 행동 해석과 역계획을 이용한 PAM 규칙 갱신 — 연구 방향

작성일: 2026-11-01 · 갱신일: 2026-11-02

> 이 문서는 11월 2일에 작성한 촬영본 비교 계획이다. 이후 글로 만든 15개 장면에서 역계획을 포함한 의도 추정 방식 세 가지를 비교했다. 실제 촬영본에 대한 비교는 아직 실행하지 않았다. [11월 4~6일 실험 결과](../../2026-11-06_intent-inference-comparison/)

사용자가 직접 한 일과 도움 이후 행동을 보고, 로봇이 언제 무엇을 대신할지에 대한 규칙을 생성·수정하는 방법을 검토한다. 장기적인 개인 선호를 추정하는 목표는 남아 있지만, 첫 실험은 관찰 가능한 행동의 해석과 도움 규칙 갱신으로 좁힌다. h(도움 자체에 대한 선호)·w(개입 특성별 간섭 민감도)의 수치 표현이나 학습식은 확정하지 않았다.

이 문서는 박석준의 연구 검토 기록이다. 팀이 합의한 제품 요구사항이나 통합 구조의 변경을 뜻하지 않는다.

## 이번 실험에서 정한 범위

1. 실제 로봇의 물건 운반 대신, 실제 영상에 대한 AI의 판단을 비교한다. 영상 속 보조자는 로봇의 도움 동작을 대신 수행한 사람이다.
2. 사용자가 먼저 직접 음료를 가져오는 관찰에서 첫 도움 규칙을 생성한다. 처음부터 “공부하면 음료 제공” 규칙을 정답으로 넣지 않는다.
3. 역계획은 사용자 관찰의 분석, 도움 이후 반응 해석, 자기반성에서의 규칙 생성·수정에 적용하는 방향으로 검토한다. 트리거가 발생한 뒤 행동 직전에 역계획을 추가하는 방식은 이번 범위에서 미룬다.
4. 로봇의 수행 가능한 행동은 사전에 정하고, 그중 언제 무엇을 할지에 대한 규칙을 배우게 한다. 물 제공·캔음료 제공·물 정리·캔음료 정리와 대기는 행동 목록 후보이며, 최종 목록과 각 행동의 평가 장면은 아직 확정하지 않았다.
5. 사용자 반응의 의미를 고정 대응표로 정하지 않는다. 촬영한 반응의 구분은 평가에만 쓰고, 모델에는 네 가지 중 하나를 반드시 고르게 하는 선택지나 영상별 정답을 주지 않는다.

## 확보한 촬영 자료

[영상 목록과 확인 근거](../../2026-11-02_drink-handoff-videos/video_inventory_2026-11-02.json)에 파일별 길이, 내용, 중복 관계와 평가용 촬영 의도를 기록했다. 원본 영상과 얼굴이 포함된 미리보기는 이번 문서 업로드에 포함하지 않는다.

로컬에서 파일 11개를 확인했다. 화면을 복원한 결과가 완전히 같은 한 쌍이 있어 영상 화면 기준으로 서로 다른 촬영본은 10편이다. 모든 파일의 저장 해상도는 1920×1080이고 길이는 약 11~27초이다. 대부분의 보조자 개입 영상은 회전 정보를 반영하면 세로 영상이며, 카메라가 보조자의 이동을 따라 움직인다. 처음 제안한 고정 가로 촬영 조건과 실제 입력의 차이를 실험 설정에 기록해야 한다.

사용자가 직접 음료를 가져오는 영상은 두 편이다. 하나는 노트북 작업 중 캔음료를 가져와 마시는 장면이고, 다른 하나는 책을 읽다가 물병을 가져와 마시는 장면이다. 보조자 개입 영상은 두 작업 상황에서 다음 네 반응을 각각 촬영한 여덟 편이다.

1. 가져다준 음료를 곧바로 마신다.
2. 작업을 이어가다가 나중에 음료를 마신다.
3. 고개를 저어 거절한다.
4. 음료를 원래 장소로 돌려놓아 거절한다.

위 네 항목은 **촬영자가 설명한 연출 의도에 따른 평가용 구분**이다. 로봇이 실제로 선택한 행동 기록이나 자연스러운 장기 선호의 측정값이 아니다. 시간순 표본 프레임으로 장면을 검토했고, 물을 나중에 마시는 장면은 더 촘촘한 프레임으로 확인했다. 고개 젓기 장면의 거절 의도는 촬영자의 설명으로 확인했다. 오디오에 대한 분석은 하지 않았다.

반환 장면에서 왜 거절했는지까지 확인한 것은 아니다. “이미 자기 음료가 있어서 돌려놓았다”는 초기 촬영 제안과 실제 촬영본의 확인 내용을 혼동하지 않는다. 현재 영상에서는 작업 종류와 음료 종류가 함께 바뀌므로, “책을 읽을 때는 항상 물을 선호한다” 같은 일반적인 선호를 확인했다고 말할 수 없다.

## AI를 바꾸는 구조 — 구현 전 제안

기존 Qwen 모델을 유지하고, 모델에 맡기는 역할과 명시적인 계획 계산 부분을 구분하는 방안을 제안한다. 이 실험에서 기억을 배운다는 것은 신경망을 새로 학습시키는 것이 아니라, 이후 판단에 사용하는 규칙과 근거를 생성·갱신한다는 의미다.

1. **영상 관찰:** 사용자와 보조자를 구분하고, 물건의 위치·이동·사용과 작업의 진행을 시간순으로 기록한다. 반응 직후의 짧은 고개 움직임과 이후 지연 사용을 모두 볼 수 있게 사진 추출 간격과 관찰 길이를 설계한다. 관찰 사실과 의미 해석은 분리한다.
2. **역계획 분석:** 가능한 사용자 목표를 가정해 행동 계획을 만들고, 관찰된 행동 순서가 각 목표에서 얼마나 설명되는지 비교한다. 역계획은 목표에서 행동을 예측하는 계획 모형을 거꾸로 사용해 목표를 추정하는 방법이다. 상태·행동·동작 조건·비용·목표 후보 생성 방법과 점수 계산식은 아직 정하지 않았다. 단순히 “역계획으로 생각하라”는 지시문을 추가한 것을 별도 계획 계산 구현으로 보고하지 않는다.
3. **첫 자기반성:** 사용자 단독 행동에서 로봇이 대신할 기회를 찾고, 허용된 로봇 행동과 연결해 관찰 가능한 도움 조건을 만든다. 로봇이 먼저 도와주면 사라질 사용자 행동 자체를 시작 조건으로 삼지 않도록 검토한다.
4. **도움 이후 반응 분석:** 즉시 사용하지 않았다는 이유만으로 거절을 확정하지 않는다. 명시적인 거절과 그 이유도 구분한다. 여러 설명이 가능하면 근거와 미확인 사항을 함께 남긴다.
5. **다음 자기반성:** 관찰 사실과 해석 후보를 이용해 규칙을 유지·수정·제외할지 판단한다. AI가 추정한 반응을 사람이 직접 말한 권위 있는 피드백 입력에 섞지 않는다. 반응 근거와 반대 근거는 규칙과 연결해 별도로 저장하는 방안을 검토한다.
6. **행동 판단:** 수정된 FSM, 즉 상황별 도움 규칙과 전환을 담은 기억을 기존 판단 모델이 참고해 지금 할 행동이나 대기를 선택한다. 행동 직전에 역계획 계산을 추가하지 않는다.

같은 도움 전 상황에서 사용과 거절이 모두 나오는데 차이를 설명할 관찰 단서가 없다면, 미래 반응을 미리 구분할 수 있다고 가정하지 않는다. 고개를 저어 거절했다는 판단과 “이 음료를 항상 싫어한다”는 장기 선호는 다른 주장이다.

## 기존 PAM 및 현재 코드와의 차이

PAM은 하루 동안 고정된 기억을 참고해 행동을 고르고, 하루 기록을 검토해 다음 날 사용할 기억을 갱신한다. 자기반성은 사용자 행동에서 도움 기회를 찾아 조건과 행동을 작성하는 언어 모델의 추론 과정이다. 행동 판단 모델은 FSM 전체를 문맥으로 참고하며, 코드가 현재 상태 하나와 문구의 정확한 일치만으로 행동을 강제하는 방식이 아니다.

현재 저장소는 논문과 부록에 근거해 작성한 상황 변경 구현이며 저자의 공식 실행 코드가 아니다. 이번에 원문 지시문 7개와 PDF가 보관된 원문 해시 기록에 일치함을 확인했다. 이것은 전체 시스템의 동작이나 성능이 논문과 동일하다는 증거가 아니다.

[기존 실험 실행기](../../pam/reflection_experiment.py)는 초기 기억을 파일에서 읽고, 고정된 아침 시나리오와 사람이 제공하는 요약·피드백을 사용한다. 논문에서는 사용자 피드백이 선택 사항이지만 이 실행기는 빈 피드백을 거부한다. [기억 입력 준비](../../pam/messages.py)에는 처음부터 기억을 생성하는 기능이 있으나, 이번 음료 영상 전체 흐름을 실행하도록 연결된 상태는 아니다.

[영상 입력](../../pam/observations.py)은 두 카메라를 전제로 하고, [기억 저장](../../pam/memory_store.py)은 다음 달력 날짜에 갱신 기억을 적용한다. 한 카메라의 실제 촬영 영상과 같은 날 반복하는 실험 회차를 지원하는 입력·기억 관리 경로가 필요하다. [결과 형식 검사](../../pam/contracts.py)는 구조와 행동 번호 등을 확인하며 개입의 적절성을 보장하지 않는다.

새 반응 분석 부분과 역계획 계산은 추가 구현 대상이다. 기존 아침 식사 실험의 성공·실패 기록을 이 제안의 검증 결과로 사용하지 않는다.

## 비교 계획 — 아직 실행하지 않음

초기 규칙 생성은 일반 자기반성과 역계획을 사용하는 자기반성을 같은 사용자 관찰 자료로 비교한다. 이후 반응 분석과 수정의 영향을 따로 볼 때는 같은 초기 규칙에서 출발하도록 설계한다.

1. **논문 흐름의 기준 방식:** 영상과 행동 기록을 기존 자기반성에 넣어 규칙을 수정한다. 음료 시나리오와 한 카메라 입력으로 바뀐 조건은 별도 기록한다.
2. **일반 분석 추가:** 별도 언어 모델 분석으로 반응을 해석하고 자기반성에 전달한다. 분석 단계와 정보가 늘어난 효과를 확인하는 비교 조건이다.
3. **반응 분석에만 역계획:** 도움 이후 개별 반응을 역계획으로 해석하고, 규칙 수정은 일반 자기반성으로 한다.
4. **자기반성에만 역계획:** 개별 반응은 일반적으로 분석하고, 누적 기록에서 규칙을 생성·수정할 때 역계획을 사용한다.
5. **두 곳 모두 역계획:** 반응 분석과 자기반성에 함께 적용한다.

모델, 영상, 허용된 로봇 행동과 최종 행동 판단 부분을 맞춘다. 역계획에 제공하는 추가 목표·환경 정보는 정보량을 맞춘 일반 분석 비교 조건에도 제공한다. 호출 수, 사진 수, 사용한 계산량과 시간이 다르면 함께 기록한다. 같은 관찰을 두 단계에서 사용했다고 서로 독립된 증거처럼 중복 계산하지 않도록 해야 한다.

관찰 행동의 해석, 근거 없는 장기 선호 추론 여부, 규칙 수정 내용, 새 영상에서의 행동 선택과 개입 시점을 비교하는 방향이다. 규칙이 많이 바뀌었다고 좋은 결과로 평가하지 않는다. 현재 영상에서 네 반응을 맞힌 것만으로 도움 선택이나 개인화의 개선을 입증하지 않는다.

개입 시점은 시험 영상을 시간순으로 보여주면서 그 시점까지의 정보만으로 평가해야 한다. 개입 가능 구간과 행동의 정답을 사전에 별도 기록하고, 조기·불필요한 개입, 지연, 도움 누락을 구분한다. 이 구간과 판정 기준, 자료 분할은 아직 확정하지 않았다.

## 남은 결정과 다음 작업

1. 원본 영상별 개입 시각과 관찰 가능한 구간을 기록하고, 중복 촬영본을 제외한 자료 분할을 확정한다. 같은 촬영본의 인접 프레임이나 중복본을 규칙 생성용과 시험용으로 나누지 않는다.
2. 네 가지 촬영 의도는 평가에만 보관하고, 모델의 입력·출력에 고정 반응 선택지를 강제하지 않는다. 자유롭게 생성된 해석을 어떤 기준으로 평가할지 정한다.
3. 로봇 행동 목록을 확정하고, 물 제공·음료 정리 등 각 행동의 적절성을 평가할 장면이 있는지 확인한다. 지금 확인한 파일에는 별도의 “이미 음료가 있는 공부”·“공부 마무리” 시험 장면이 확보됐다고 기록하지 않는다.
4. 한 카메라 영상 입력, 사실 기록, 초기 규칙 생성, 반응 분석, 규칙 수정, 시험 실행을 연결한다.
5. 역계획의 목표 후보 생성, 상태 전이, 비용과 점수 계산, 미확인 결과의 처리 방법을 구체화한 뒤 비교한다.
6. 실제 모델 입력과 응답, 규칙 변경, 평가 결과를 저장한다. 첫 실행 목표는 2026-11-03이며, 현재는 구현·비교 실행 전이다.
