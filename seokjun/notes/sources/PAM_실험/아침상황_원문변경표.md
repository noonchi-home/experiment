# 아침 상황에 적용한 원문 변경

논문 부록 E의 세 판단 지시문과 부록 F의 네 기억 생성·갱신 지시문은 `prompts/paper/`에 보존한다. `scenarios/morning/scenario.json`의 `prompt_replacements`에는 줄바꿈을 포함한 원문 문자열, 바꿀 문자열, 이유를 저장한다. 아래 변경은 그 원문이 실제로 있는 지시문에만 적용한다.

| 바꾸는 부분 | 원문 | 아침 상황 | 적용 범위 |
|---|---|---|---|
| 생활 공간 | 한 사람의 개인 책상 | 침실·아침 식탁·주방 싱크대·출입구가 있는 집 | 지시문 7개 모두 |
| 물체와 보관 위치 | 시리얼·그릇·우유 등을 두는 책상 모서리 | 우유를 두는 주방 보관 표면, 식탁의 컵·접시, 사용한 그릇을 둘 싱크대 | 지시문 7개 모두 |
| 물체를 내려놓는 곳 | 사람이 책상에 내려놓을 때까지 해당 물체를 옮기지 않음 | 사람이 안정적인 표면에 내려놓을 때까지 해당 물체를 옮기지 않음 | 판단 지시문 3개, 목록형·상태형 기억 최초 생성 지시문 2개 |
| 도움을 받아도 남는 관찰 신호의 예시 | 책상에 앉기 | 아침 식탁에 앉기 | 목록형 기억 최초 생성 지시문 |
| 기억 행동의 허용 목적지 | 사용자 곁·보관 위치·쓰레기통 | 기존 목적지에 싱크대 추가 | 기억 생성·갱신 지시문 4개 |
| 기억 출처를 설명하는 문장 | 과거 행동을 되돌아보며 만든 기억 | 이미 확립된 아침 생활을 설명하는 기억 | 기억을 사용하는 판단 지시문 2개 |

마지막 변경은 초기 기억을 실제 관찰 학습 결과라고 오해하지 않게 한다. 이 문장에 수동 입력을 영구적으로 고정하지는 않는다. 현재 파일이 사람이 쓴 초기 기억이라는 사실은 별도 `provenance.json`에 명시하므로, 이후 모델이 갱신한 기억도 같은 판단 지시문을 사용할 수 있다.

원문의 행동 문장 형식 `Pick up <object> and place it <location>.`은 유지한다. 판단기에 주는 행동 목록만 우유를 사용자 곁에 두기, 컵을 싱크대에 두기, 접시를 싱크대에 두기로 구성한다. 우유의 목적지를 식탁으로 새로 제한하지 않은 이유는 사용자가 우유를 가져다준다고 했고 원문의 사용자 곁이라는 표현으로 충족하기 때문이다.

초기 습관은 사용자가 이미 알고 있다고 가정하도록 요청한 조건이다. 음식이 바뀌어도 우유를 마시는 습관과 외출 뒤 남은 식기를 정리하는 규칙을 부록 F의 기억 형식으로 직접 작성했다. 생활 단계 이름, 다섯 단계의 구분, 관찰 조건의 정확한 문장은 우리 상황에 맞게 재구성한 부분이다. 실제 5일을 촬영했거나 모델이 그동안 학습했다고 주장하지 않는다.

사진에서 사람이 잠시 보이지 않는 것과 집을 나간 것은 다르므로, 정리 규칙에는 식사 종료와 일부 정리 뒤 출입구를 통해 외출한 관찰을 포함한다. 망각이라는 마음속 상태를 정답으로 넣지 않는다. 컵과 접시가 모두 남아 있으면 어느 하나를 먼저 고를 수 있고, 두 물체를 한 행동으로 묶거나 코드에서 우선순위를 부여하지 않는다. 우유가 이미 제공되었거나 물체를 사람이 잡고 있는 상황도 기억과 원문 조건에 따라 검토할 수 있게 한다.

세 행동의 순번은 선택 결과를 글로 표시하는 데만 사용한다. 사진별 정답, 목표 행동 번호, 장면 이름을 초기 기억에 넣지 않았다. 실제 사진에서 적절한 선택인지 판단하는 일은 PAM의 모델 호출과 사용자의 결과 확인으로 남아 있다.

원문의 판단 기준, `observation`·`reasoning`·`task_index` 출력 구조, 한 번에 한 행동 또는 대기, 여러 상태의 기억을 전체적으로 참고하는 방식, 기록을 바탕으로 기억을 생성·갱신하는 지시문은 유지한다. 시리얼과 그릇으로 설명하는 원문 예시는 같은 물체를 이미 집고 있을 때 개입하지 말라는 일반 규칙의 설명이므로 바꾸지 않았다. 사진 5장과 두 카메라 합성, 2초 간격, 모델 설정은 원문 설정 파일이 계속 담당한다.

검증은 원문 파일 해시가 그대로인지, 치환 문자열이 실제 원문에 있는지, 일곱 지시문에 필요한 공간 변경이 적용되는지, 목록형 기억과 상태별 기억의 행동 규칙이 같은지 확인한다. 이는 파일과 입력 구성에 대한 시험이며, 모델의 사진 이해 성능을 검증한 결과와 구분한다.
