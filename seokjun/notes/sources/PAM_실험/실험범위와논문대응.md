# PAM 논문 재현 범위와 구현 기준

목표는 PAM 논문의 시스템을 원문에 명시된 구성과 설정대로 재구현하는 것입니다. 바꾸는 것은 생활 상황과 로봇 실행 부분입니다. 생활 상황을 아침 기상·우유 준비·식사 후 외출과 남은 식기 정리로 바꾸고, 판단기가 로봇 실행기에 전달하던 행동 선택 결과를 글로 표시합니다. 사용자는 사진과 결과를 보고 선택이 적절한지 확인합니다.

원문에 나온 부분은 원문을 구현 계약으로 삼습니다. 공개되지 않은 구현 세부사항은 논문의 동작을 보존하는 방향으로 재구성하고, 근거와 영향을 별도로 기록합니다. 단순한 개념 시연이나 임의로 단순화한 판단 프로그램으로 대체하지 않습니다.

## 사용자가 정한 조건

- 로봇을 직접 움직이지 않고, 해야 할 행동을 글로 표시합니다.
- 한 번의 판단에 최근 8초에 해당하는 사진 5장을 시간순으로 입력합니다.
- 사용자의 습관은 이미 알고 있다고 가정해 초기 PAM 기억을 제공합니다. 실제로 5일 동안 학습한 결과라고 표현하지 않습니다. 이 시작 조건은 논문의 기억 생성·갱신 기능을 재현 범위에서 빼는 뜻이 아닙니다.
- ‘일어난다’는 아침에 잠에서 깨어 침대에서 일어나는 장면입니다.
- 아침 음식은 달라져도 우유는 항상 마시는 습관을 가정합니다. 기상 장면에서 우유를 준비하는 도움을 판단합니다.
- 식사가 끝나고 사용자가 일부 물건을 정리한 뒤 외출했는데 컵과 접시가 남은 경우, 싱크대로 옮기는 도움이 적절한지 판단합니다.
- 사용자가 밖에 있어 직접 촬영하기 어려우므로, 작은 규모의 합성 사진으로 시작할 수 있습니다.
- 논문의 PAM, 즉 활동 단계와 도움 조건을 구조화한 기억을 사용합니다.

## 원문에서 유지할 구현 계약

| 항목 | 논문 내용 | 이번 실험에서의 적용 |
|---|---|---|
| 최근 관찰 | 현재와 2초·4초·6초·8초 전의 사진, 최종 사진의 시각 | 같은 시점 선택과 시간순 입력을 유지 |
| 판단 주기 | 초당 1장인 관찰 흐름에서 매초 최근 사진 묶음을 갱신 | 같은 시간표의 판단 반복을 구현; 묶음 한 건 실행은 점검 수단 |
| 카메라 | 한 시점마다 두 카메라의 왼쪽·오른쪽 화면을 가로로 연결; 손목 카메라는 판단에 제외 | 두 카메라 입력을 유지; 기존 한 카메라 예시를 원문 조건을 충족한 자료로 간주하지 않음 |
| PAM 절차 기억 | 초기 단계, 각 활동 단계의 설명·규칙·다음 단계 연결 | 부록 38·40쪽의 실제 기억 형식을 유지하고 내용만 우리 생활 상황으로 변경 |
| 기억 사용 | 모델이 기억 전체를 문맥으로 해석 | 단계나 조건 문구를 엄격하게 일치시키는 규칙 프로그램으로 대체하지 않음 |
| 행동 선택 | 지금 적절하고 즉시 가능한 행동 하나 또는 대기; 사람이 잡거나 접촉 중인 물체에는 행동하지 않음 | 선택 규칙을 유지하고, 우유·컵·접시 및 식탁·싱크대에 맞춰 행동 목록만 변경 |
| 판단 지시문 | 부록 E의 기억 없음·목록 기억·단계 구조 기억 지시문 | 원문을 보관하고 환경·물체·장소·행동 목록의 변경만 차이로 기록 |
| 출력 | observation은 관찰 한 문장, reasoning은 짧은 판단 근거 한 문장, task_index는 선택 번호 또는 대기를 뜻하는 -1 | 원문 JSON 출력 구조를 유지; 행동 번호를 화면용 행동명으로 바꿔 표시하고 원본 응답도 저장 |
| 판단 모델 | Qwen3.5-27B를 vLLM 모델 실행 서버로 구동, thinking 비활성화, 생성 온도 0.3 | 동일 모델·서버 방식·생성 설정을 기본 재현 경로로 사용; 서버 주소와 장비는 구현 준비 시 결정 |
| 기억 생성·갱신 | 같은 Qwen 모델, thinking 활성화, 생성 온도 0.3; 하루말 한 번, 하루 관찰을 균등하게 추린 200장과 기존 기억·행동 요약·있을 때 피드백 사용 | 부록 F의 생성·갱신 지시문과 절차를 구현 범위에 포함; 이미 기억을 제공한 시작에서는 초기 생성만 생략 가능 |
| 하루 중 기억 | 하루 동안 고정하고 하루말 갱신 결과를 다음 날 사용 | 매 판단마다 임의로 기억을 수정하지 않음 |
| 로봇 실행 | 선택한 행동을 별도 로봇 제어 모델이 수행 | 사용자 요청에 따라 실행기 대신 행동을 글로 표시하는 출력을 연결 |

논문 근거: [원문](../papers/2610.21211v1.pdf)의 방법 설명 4~5쪽, 설정 15~16쪽, 판단 지시문 31~34쪽, 기억 생성·갱신 지시문 34~40쪽. 31쪽은 지시문에 남아 있는 ‘초당 1장’ 표현과 실제 입력 사진 사이의 2초 간격을 구분해서 설명합니다.

OpenAI 모델로의 교체는 현재 원논문 재현 경로에 포함하지 않습니다. 별도로 비교할 경우 모델 변경 실험으로 분리합니다. API는 프로그램이 모델을 호출하는 방식이며, 모델 이름과는 구분합니다. 아직 API 인증이나 모델 실행을 수행하지 않았습니다.

논문의 지시문 원문에 남은 ‘초당 1장’ 표현과 실제 2초 간격의 입력 설정을 함께 보존해 기록합니다. 실행에서 사진 선택은 부록 A.2의 실제 설정을 따릅니다. 프롬프트 표현을 조용히 수정하고 원문 그대로라고 표시하지 않습니다.

## 실행용 기억 형식

부록 F의 기억은 다음 정보를 가집니다. 영문 이름은 프로그램에서 실제로 사용하는 필드 이름입니다.

- initial_state: 시작 활동 단계의 식별자.
- states: 활동 단계 목록. 각 단계는 id라는 식별자와 description이라는 설명을 가집니다.
- 각 단계의 rules: trigger라는 관찰 가능한 시작 조건과 action이라는 도움 행동의 목록.
- 각 단계의 next: to라는 다음 단계 식별자와 on이라는 전환 사건의 목록.

공개 저장소의 pam-fsm.json은 웹페이지 표시용으로 날짜·설명·새 항목 표시와 별도 연결 목록을 포함합니다. 그 구조를 실행용 기억 형식으로 그대로 복사하지 않습니다. 공개 예시의 내용을 사용할 때는 부록의 실제 형식으로 옮기고 대응을 확인합니다.

기억은 단계별 조건을 엄격하게 강제 실행하는 제어기가 아닙니다. 부록 E.3처럼 모델이 단계 설명·규칙·연결 전체를 참고해 의미상 적절한 행동을 선택하게 합니다.

부록 F의 행동 문장과 허용 목적지에도 원문 제약이 있으므로, 싱크대를 추가할 때 환경 설명과 목적지 대응을 함께 수정해 기록합니다. 관찰한 인간 행동을 근거로 규칙을 만들고 갱신하는 원칙, 사용자 피드백을 반영하는 원칙, 오늘 등장하지 않았다는 이유만으로 기존 규칙을 지우지 않는 원칙도 유지합니다.

## 원문 명시 내용과 재구성의 구분

| 구분 | 포함되는 내용 | 기록 원칙 |
|---|---|---|
| 원문 명시 | 모델, 입력 시점, 두 카메라 결합, 생성 설정, 기억 형식, 판단·갱신 지시문 | 원문 쪽수와 원본을 보존 |
| 사용자 지정 변경 | 생활 상황, 물체와 목적지, 로봇 실행을 글 출력으로 교체, 이미 습관을 아는 시작 조건 | 무엇을 왜 바꿨는지 기록 |
| 원문 미공개 구현 | 호출 연결, 파일 입출력, 오류 응답 처리, 반복 호출의 세부 일정 관리 등 실제 소스에 필요한 부분 | 원문에서 확인한 사실과 추론한 선택을 구분하고 영향 기록 |

원문에 없는 확률 점수, 행동 기준값, 추가 관찰 정책, 임의의 행동 우선순위를 논문의 알고리즘이라고 추가하지 않습니다. 외출 후 정리처럼 새 상황에서 필요한 행동 명세와 평가 정답은 상황 변경에 따른 설계로 표시합니다.

## 판단 과정

1. 사진 5장의 순서와 시각을 확인합니다.
2. 활동 단계와 도움 조건을 담은 PAM 기억, 가능한 행동 목록을 함께 준비합니다.
3. 사진과 기억을 모델에게 제공해 지금 가능한 도움 행동 하나 또는 대기를 선택하게 합니다.
4. 원본 응답과 사용자에게 보여 줄 관찰·행동·근거를 저장합니다.
5. 모델에 제공하지 않은 평가용 정답과 비교하고, 사용자가 사진을 보며 검토할 수 있게 합니다.

이 과정은 논문의 동작을 설명한 절차입니다. 별도의 습관 점수 공식이나 새 학습 손실함수를 논문이 제공했다고 가정하지 않습니다. 논문에서 소개하는 정밀도·재현율·F1은 선택 결과를 평가하는 지표입니다.

## 현재 사진의 상태

[data/wakeup](../data/wakeup/)에는 누워 있음, 상체를 일으킴, 침대 가장자리에 앉음, 일어서는 중, 서 있음으로 이어지는 합성 사진 5장이 있습니다. 각 사진에 부여한 시점은 실제 촬영 시간이 아니라 2초 간격을 가정한 값입니다.

이 사진 묶음은 기상 입력 예시 한 건입니다. 한 카메라만 가정했고 연속적인 매초 관찰도 아직 갖추지 않았으므로, 원문과 같은 두 카메라·시간표의 평가 자료로 완성된 상태가 아닙니다. 식사와 외출 전체를 같은 8초 안에 넣지 않습니다. 식사 후 정리는 별도의 관찰 흐름으로 만듭니다. 현재 사진을 본 별도 판단 모델의 결과나 성능 점수는 없습니다.

## 다음 작업

1. 논문 부록 E·F의 원문 지시문과 기억 형식을 옮기고, 원문에 없는 구현 선택을 기록할 목록을 만듭니다.
2. 모델 호출, 사진 선택·두 카메라 결합, 판단 반복, 기억 생성·하루말 갱신, 원문 응답 저장을 재구현합니다.
3. 환경·행동 목록과 초기 기억만 우리 상황에 맞춥니다. 처음부터 알고 있다고 가정하는 습관이라는 출처를 기록합니다.
4. 두 카메라와 원문의 시간표에 맞는 작은 관찰 자료를 준비합니다. 사람이 보이지 않는다는 사실만으로 외출이나 망각을 확정하는 정답을 만들지 않습니다.
5. 동일 Qwen 모델을 실제로 호출해 원문 출력 형식을 확인하고, 행동을 글로 표시합니다.
6. 논문의 판단 평가를 참고해 기억 없음·조건과 행동만 있는 기억·단계와 연결까지 있는 기억을 동일 자료에서 비교합니다. 이 비교는 재현한 시스템의 평가이며 프로젝트의 구현 범위를 대신하지 않습니다.

한 번에 하나의 행동을 고르는 논문 형식을 유지하면 컵과 접시 정리는 별도 행동이 됩니다. 논문의 시점별 한 행동 정답 형식을 유지하려면 여러 행동이 가능한 장면의 정답 선정 기준을 먼저 정하고 기록합니다. 복수 정답 평가를 추가한다면 원문과 다른 평가 방식임을 표시합니다. 글로 행동을 출력했다고 물건이 실제로 옮겨진 것으로 관찰 데이터를 변경하지 않습니다. 기억 갱신에 쓰는 행동 요약에서도 출력된 제안과 실제 사람이 수행한 행동을 구분합니다.

기상 한 건의 성공만으로 일반 성능을 주장하지 않고, 기다려야 할 때 불필요한 도움을 선택하는지도 확인합니다. 시간에 따른 반응 지연은 연속 시점별 입력을 구성한 뒤 평가합니다.
