# 역계획 설계 초안 (2026-11-04, 구현 전)

## 결론 먼저

1. **추천 계산법: «언어 모델 확률로 목표의 그럴듯함을 계산」(아래 방법 A).** Qwen이 목표 후보를 만들고, 각 목표에서 실제로 본 행동이 나올 확률을 모델의 단어 확률(로그 확률)로 재서, 어떤 목표가 행동을 가장 잘 설명하는지 계산한다. 지시문으로 «목표를 생각해 보라»고만 하는 것은 역계획 구현이 아니라 비교 조건 2(일반 분석)로만 쓴다.
2. **넣는 순서: 먼저 4일 영상에서 «자기반성에만 역계획»(조건 4), 그다음 11-02 음료 영상에서 «반응 해석에 역계획»(조건 3·5).** 4일 영상에는 로봇 도움과 그에 대한 반응이 없어서, 반응 해석 조건은 음료 영상에서만 의미가 있다.
3. **돈: 4일 영상 조건 하나에 약 40분·약 $2.7, 음료 영상 조건 하나에 약 45분·약 $3(추정).** 계획한 조건을 모두 돌리면 약 $23 안팎이다. RunPod 잔액은 지금 실험 전 $33.61이었다.
4. **사용자가 정할 것:** 계산법(A/B), 목표 후보를 누가 만들지, 어떤 조건까지 돌릴지(아래 6절).

## 1. 역계획이 뭔가 (한 줄)

«이 사람의 목표가 무엇이었다면 이런 행동이 나왔을까»를 거꾸로 계산하는 방법이다. 목표 후보마다 «그 목표라면 이 행동이 나올 가능성»을 매기고, 가장 잘 설명하는 목표를 고른다(Baker·Saxe·Tenenbaum 2009의 기본 생각).

## 2. PAM 흐름 어디에 넣나 — 비교 조건

연구 문서(`ai/docs/research/개인별선호모델_연구방향.md`, «비교 계획»)의 5개 조건 + 기억 없음.

| 조건 | 사용자 반응 해석 단계 | 자기반성(규칙 만들기·고치기) 단계 | 4일 영상(A1→B2)으로 | 11-02 음료 영상으로 |
|---|---|---|---|---|
| 기억 없음 | — | 없음 | 완료(A2·B1·B2) | 돌릴 수 있음 |
| 1 기준(논문 방식) | 없음 | 일반 자기반성 | 진행 중(원래 세션) | 돌릴 수 있음 |
| 2 일반 분석 추가 | 일반 분석 | 일반 자기반성 + 분석 글 | 돌릴 수 있음(하루 행동 분석) | 돌릴 수 있음 |
| 3 반응 해석에만 역계획 | 역계획 | 일반 자기반성 | **조건 1과 같아짐**(반응 없음) | 돌릴 수 있음 |
| 4 자기반성에만 역계획 | 일반 분석 | 역계획 결과를 넣은 자기반성 | 돌릴 수 있음 | 돌릴 수 있음 |
| 5 두 곳 모두 | 역계획 | 역계획 결과를 넣은 자기반성 | **조건 4와 같아짐** | 돌릴 수 있음 |

- 4일 영상에서는 사용자가 모든 일을 직접 했고 로봇 도움 장면이 없다. 그래서 «도움 이후 반응»이 없어 조건 3=1, 5=4가 된다.
- 연구 문서 원칙: 역계획에 주는 추가 정보(목표 후보·환경 정보)는 조건 2(일반 분석)에도 똑같이 준다. 기계가 추정한 해석은 사람 피드백 칸에 섞지 않는다. 행동 직전(행동 고르기)에는 역계획을 넣지 않는다.

## 3. 계산 방법 3안

| 방법 | 무엇을 하나 | 근거 문헌(확인 정도) | 나쁜 점 |
|---|---|---|---|
| **A. 언어 모델 확률로 가능성 계산** (추천) | ① 하루 사건 목록 만들기(행동 고르기가 1초마다 쓴 장면 설명을 Qwen이 글로만 받아 «20초 폰 내려놓음, 23초 일어나 나감…»처럼 정리) ② Qwen이 목표 후보 생성(예: «목이 마름», «곧 노트북 작업», «잘 준비») ③ 각 목표에서 다음 사건이 나올 확률을 Qwen의 단어 확률(로그 확률)로 계산 ④ 사전 확률 × 가능성 → 사후 확률, 날마다 누적 ⑤ 상위 목표와 근거 사건을 «기계 추정 분석» 표시와 함께 자기반성 입력에 붙임 | MMToM-QA(BIP-ALM): 언어 모델로 행동 가능성을 매김(11-03 arXiv 원문 확인. 단 시뮬레이터 정답 상태와 추가 학습한 GPT-J·LLaMA2를 씀, 정확한 계산식은 이번에 다시 확인 못 함) · CLIPS: 언어 모델이 사람 말의 가능성을 매김(검색 요약만) · AutoToM: 언어 모델을 바탕으로 베이즈 역계획 자동화(초록만 확인, 가능성 계산 방식은 확인 못 함) | 로그 확률은 문장 길이·표현에 민감해서 보정이 필요하다. 사건 목록이 틀리면 결과도 틀린다. vLLM에서 입력 문장의 로그 확률(`prompt_logprobs`)이 실제로 나오는지 확인 못 함(서버 모델 목록에 «allow_logprobs: true»는 봤음). 우리 Qwen은 추가 학습을 하지 않는다(MMToM-QA와 다름). |
| **B. 작은 기호 계획 모형** | 상태(물건 위치·사람 활동), 행동(가져오기·치우기·마시기·읽기·끄기), 비용을 손으로 정하고, 목표마다 최적 계획을 계산해 관찰 사건과 비교(합리적 행동일수록 가능성 높음) | Baker·Saxe·Tenenbaum 2009(초록 확인, 미로 속 움직이는 그림) | 우리 일과에 맞춰 상태·행동·비용을 사람이 짜야 해서 평가자 지식(촬영 의도)이 모델에 새어 들어갈 위험이 크다. 새 일과에 일반화가 안 된다. 사건 목록 오류에 약하다. 장점: 계산이 투명하고 모델 호출이 적다. |
| C. 지시문으로만 목표 추정 | «가능한 목표를 생각하고 어느 것이 행동을 설명하는지 판단하라»를 분석 지시문에 넣음 | — | 연구 문서 원칙상 «별도 계획 계산 구현»이 아니다. 그래서 역계획 결과로 보고하지 않고, 조건 2(일반 분석)로만 쓴다. |

추천 이유: A는 우리가 이미 띄울 수 있는 Qwen(직접 올린 vLLM)만으로 되고, 목표 후보를 사람이 정하지 않아도 된다. B는 A의 결과가 이상할 때 작은 장면(예: B1 비타민→컵)에서 검산용으로만 쓴다.

## 4. 우리 자료로 돌리는 법

### 4.1 4일 영상(A1→A2→B1→B2)

- 돌릴 조건: 조건 2(일반 분석), 조건 4(자기반성에 역계획). 기억 없음과 조건 1은 원래 세션에서 진행 중이거나 끝났다.
- 하루 끝 흐름: 행동 고르기(1초마다) → 사건 목록 → (조건 2) 일반 분석 1번 / (조건 4) 역계획 계산 → 결과를 하루 요약 뒤에 «분석(기계 추정, 사람 피드백 아님)»으로 붙여 자기반성.
- 첫날(A1)은 두 조건 모두 기억 없이 행동 고르기라서, 조건 1의 A1 결과를 그대로 쓸 수 있다(입력이 같음). 자기반성부터 달라진다.
- 평가: 기존 정답(`실험정답/4일_정답_초안.json`)으로 행동 고르기 점수 + 규칙 변화. 특히 B1(일과가 바뀌는 첫날)과 B2에서 차이를 본다.

### 4.2 11-02 음료 영상(10편)

- 처음 규칙: 사용자 혼자 가져오는 영상 2편(캔 193223629, 물 193230597)으로 만든다.
- 반응 해석: 도움 영상 8편(물·캔 × «바로 마심 / 나중에 마심 / 고개 저음 / 돌려놓음»)을 **같은 처음 규칙에서 1편씩** 넣어 반응 해석 + 규칙 고치기.
- 시험: 공부만 하는 영상 2편(노트북 31.17초, 책 31.67초)에서 1초마다 행동 고르기. 정답은 사용자가 정한 «음료 없이 공부 중 → 음료 주기, 0초부터».
- 반응 해석 평가: 촬영 의도(평가자 전용)와 비교한다. 모델 입력에는 반응 선택지를 주지 않는다.
- 주의: 도움 영상은 세로 촬영이고 카메라가 사람을 따라 움직인다. 사용자가 보이는 시간도 영상 처음 0~3.5초뿐이다(11-04 측정). 그래서 반응을 볼 수 있는 단서가 적다. 행동 목록은 11-03에 정한 음료용 10종(물병·캔·책·노트북·컵·휴지)이다.

## 6. 사용자가 정할 것

1. 계산법: A(추천) / B / A+B.
2. 목표 후보를 누가 만드나: Qwen이 영상 사건에서 만들기(추천, 평가자 정보가 안 들어감. 나쁜 점: 후보가 엉뚱할 수 있음) / 우리가 고정 목록을 주기(나쁜 점: 촬영 의도가 새어 들어가 결과가 부풀 위험).
3. 어디까지 돌리나: 4일 조건 4만 / 4일 2·4 / 음료까지 전부.
4. 분석 결과를 자기반성에 넣는 방식: 하루 요약 뒤에 글로 붙이기(추천) / 지시문에 새 입력 칸 만들기(나쁜 점: 지시문 변경이 더 커짐).

## 7. 확인 못 한 것

- vLLM에서 입력 문장의 로그 확률이 실제로 나오는지, 사진이 들어간 대화 형식에서도 되는지.
- AutoToM·CLIPS의 가능성 계산 방식 세부(초록·검색 요약만 봄).
- 짧은 음료 영상(11~27초)의 자기반성 시간과 사진 수(11-04 결정은 «100장, 영상 1편씩»이었음).
- 음료 도움 영상에서 반응을 1초 사진으로 볼 수 있는지(사람이 보이는 시간이 짧음).
- 위 비용은 모두 추정이다. 실제 실행 전에 단가·잔액을 다시 확인한다.
