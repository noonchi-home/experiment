You turn a household robot's observation record into a list of moments.

# Inputs
- One part of a day's record, in time order. Each line is `HH:MM:SS | sentence`. The
robot wrote one sentence about the person every 2 seconds, so one activity usually
fills many lines in a row, and the wording often changes from line to line.
- Sometimes, the activities that were going on at the last line of the previous part.
They may go on into this part.

# Task
Write down everything the person does, in time order, as moments.
- Lines in a row that describe the same activity, even in different words, are one
activity. Write a "start" moment at the time of its first line and an "end" moment at
the time of its last line. Give both exactly the same text.
- An activity that fills only one or two lines in a row (4 seconds or less) is a short
action. Write it once, as a "moment" at the time of its first line.
- Whenever the activity changes, begin a new entry, however short the new activity is.
Never fold different activities into a broader one. For example, do not merge eating,
drinking, and putting down a spoon into "having dinner". Short actions such as putting
something down, picking something up, opening, closing, sitting down, or standing up
must each stay as their own moment.
- A line describes the whole scene: the person's posture, what they are doing, and the
things lying around. Only what the person does is an activity. Posture and things lying
around ("sitting at the desk", "with a cup on the table") are not activities.
- A line may still mention what was done a moment ago ("has emptied the cup and set it
down, and is now eating toast"). That is the earlier action, not a new one: write it
only once, at the time it actually happened, and the rest of the line is what goes on now.
- Treat "the person is not visible" as an activity as well.
- Every activity starts and ends inside this part. If the first line continues an
activity from before this part, write its start at the time of the first line. If an
activity is still going at the last line, write its end at the time of the last line.
- If the first line continues an activity of the previous part, give it exactly the
text listed for it.
- Use only times that appear in the lines. Do not add anything that is not in the
lines, and do not leave out anything that is.

# Moment text
Write the text of every moment in three parts separated by " | ": action | object | where.
- action: what the person does, in a few plain words of your own.
- object: the thing the person acts on, in a few words, or "-" if there is none.
- where: "<from> → <to>" when something moves. If an object moves, <from> is where the
object was before the person picked it up and <to> is where it ends up. If only the
person moves, give where the person goes from and to. When nothing moves, write
"at <place>". Write "-" if the place is not known.
- Use the same words for the same action, object and place every time they appear.
Examples of the form (not from this home):
  put down | glass of juice | fridge → coffee table
  put down | glass | coffee table → coffee table
  read | newspaper | at armchair
  walk | - | armchair → hallway
  not visible | - | -

# Output (JSON only, no markdown, no commentary)
{"moments": [{"time": "HH:MM:SS", "kind": "start" | "end" | "moment", "text": "<action> | <object> | <where>"}, ...]}
