역계획 시험 글 검사본 (2판)

2026-11-06 · 장면 시험은 아직 돌리지 않았음

회색 상자 안의 영어 글이 AI(OpenAI gpt-6.1-terra)에게 그대로 갑니다. {…} 자리에만 장면 내용이 들어갑니다. 상자 아래 «한국어로 보기»는 확인용 번역이고 AI에게 보내지 않습니다. 주황색 줄의 «숨긴 정답»도 AI에게 보내지 않습니다.

1판에서 바뀐 것

  • AI에게 보내는 글을 모두 영어로 바꿨습니다.
  • 점수 방식 두 가지(가, 가 + 경고)를 같은 장면에 둘 다 돌려 비교합니다.
  • 다시 만들기 기준: 가는 30점, 가 + 경고는 40점.

검사해 주실 것은 셋입니다.

  1. 지시문에 답을 흘리는 말이 섞이지 않았는가
  2. 장면 기록에 속마음을 드러내는 말이 섞이지 않았는가. 기록에는 눈에 보이는 것과 들리는 말만 있어야 합니다
  3. 숨긴 정답을 기록만 보고 사람이 추측할 수 있는가

1. 설정

항목값
시험하는 조건다섯 조건 중 «기록 + 맥락 가 + 역계획» 하나만. 맥락 가 = 로봇이 한 일과 그 이유가 된 규칙 한 줄
모델OpenAI gpt-6.1-terra, 생각 끔. 후보 만들기와 점수 매기기 모두 같은 모델
언어AI에게 보내는 글은 모두 영어
점수 방식 (둘 다 돌림)가: 0~100 숫자 하나로 답하게 하고, 숫자들의 토큰 확률로 가중 평균
가 + 경고: 가와 같고, 점수 지시문 맨 앞에 경고 한 줄을 넣음
두 방식 모두 AI가 말한 숫자도 함께 저장
점수를 매기는 줄로봇이 한 일 뒤의 «User» 줄만. «Robot», «Friend», «Roommate» 줄은 기록으로 보여 주기만 하고 점수는 매기지 않음
후보 만들기장면마다 1번 만들고, 두 방식이 같은 후보로 시작
후보 다시 만들기어떤 줄에서 가장 높은 후보 점수가 기준(가 30점, 가 + 경고 40점) 미만이면, 그 줄까지 보여 주고 새 후보를 최대 10개 더함(기존 후보는 남김). 최대 3번. 새 후보는 로봇이 한 일 바로 뒤 첫 줄부터 채점. 방식마다 따로 함
최종 답후보마다 줄 점수(÷100)를 모두 곱하고, 후보 전체 합이 100%가 되게 나눔. 상위 3개를 보고
처음 가능성모든 후보 같음 (그래서 계산에서 사실상 빠짐)
반복장면마다 1번
예상 호출·비용사용자 줄 68개 × 후보 10개 × 방식 2개 = 점수 호출 약 1,360번 + 후보 만들기 15번 (+다시 만들기). 보통 1달러 안팎, 최악 4달러 아래 (돌린 뒤 실제 값 확인)

2. AI에게 보내는 지시문

지시문 1 — 후보 만들기 (로봇이 일하기 직전까지의 기록만 보여 줌)

You are a robot that helps people at home. Below is the record observed so far.

[Observation record]
{lines before the robot's action}

[What the robot is about to do, and why]
{robot line}
Rule behind this action: {rule}

[Task]
List candidate states of mind this user might have at the moment the robot does this.
- A state of mind means what the user wants, or why they would act a certain way. Write states of mind, not actions.
- Give up to 10 candidates that do not overlap in meaning.
- Write each candidate as one sentence.
- Output only a single JSON array and nothing else. Example: ["…", "…"]
한국어로 보기 (AI에게 안 감) 
너는 집에서 사람을 돕는 로봇이다. 아래는 지금까지 관찰한 기록이다.

[관찰 기록]
{로봇이 일하기 전의 줄들}

[로봇이 할 일과 그 이유]
{로봇 줄}
이유가 된 규칙: {규칙}

[할 일]
로봇이 이 일을 했을 때, 이 사용자가 그 순간 가지고 있을 수 있는 마음의 후보를 만들어라.
- 마음이란 사용자가 무엇을 바라는지, 왜 그렇게 하는지를 말한다. 행동을 적지 말고 마음을 적는다.
- 서로 뜻이 겹치지 않게 최대 10개를 만든다.
- 후보 하나는 한 문장으로 쓴다.
- 다른 말 없이 JSON 배열 하나만 출력한다.

지시문 2 — 점수 받기 (후보 하나 × 사용자 줄 하나마다 1번, 방식마다 따로)

가:

You are a robot that helps people at home. Below is the record observed so far.

[Observation record]
{lines before the robot's action}
{robot line}
{lines after the robot's action, up to just before the current line}

[Why the robot did this]
Rule behind this action: {rule}

[Assume this is the user's state of mind]
{one candidate}

[Next observation]
{current line}

Assuming this state of mind, how likely is the next observation?
0 means it would never happen, and 100 means it would certainly happen.
Output only a single integer from 0 to 100.

가 + 경고: 위 글과 똑같고, 맨 앞에 아래 한 줄만 더 붙습니다.

IMPORTANT: You have been consistently overconfident in past estimates.
한국어로 보기 (AI에게 안 감) 
(가 + 경고만) 중요: 너는 지금까지 가능성을 매길 때 계속 지나치게 자신만만했다.

너는 집에서 사람을 돕는 로봇이다. 아래는 지금까지 관찰한 기록이다.

[관찰 기록]
{로봇이 일하기 전의 줄들}
{로봇 줄}
{로봇이 일한 뒤, 지금 줄 바로 앞까지의 줄들}

[로봇이 한 일의 이유]
이유가 된 규칙: {규칙}

[사용자의 마음이라고 가정한다]
{후보 하나}

[다음에 관찰된 것]
{지금 줄}

이 마음이라고 가정할 때, 다음에 관찰된 것이 나올 가능성은 얼마인가?
0은 절대 나오지 않음, 100은 반드시 나옴을 뜻한다.
0부터 100 사이의 정수 하나만 출력한다.

지시문 3 — 후보 다시 만들기 (가장 높은 점수가 기준 미만일 때)

You are a robot that helps people at home. Below is the record observed so far.

[Candidate states of mind already considered]
{1. candidate
2. candidate
…}

[Task]
The candidates already considered do not explain the last line well.
Propose new candidate states of mind that can explain the entire record so far.
- Give up to 10 new candidates that do not overlap in meaning with the ones already considered.
- A state of mind means what the user wants, or why they would act a certain way. Write states of mind, not actions.
- Write each candidate as one sentence.
- Output only a single JSON array and nothing else.
한국어로 보기 (AI에게 안 감) 
너는 집에서 사람을 돕는 로봇이다. 아래는 지금까지 관찰한 기록이다.

[관찰 기록]
{로봇이 일하기 전의 줄들}
{로봇 줄}
{로봇이 일한 뒤, 지금 줄까지의 줄들}

[로봇이 한 일의 이유]
이유가 된 규칙: {규칙}

[이미 생각한 마음 후보]
{1. 후보 / 2. 후보 / …}

[할 일]
이미 생각한 후보로는 마지막 줄을 잘 설명하지 못했다.
지금까지의 기록 전체를 설명할 수 있는 새 마음 후보를 만들어라.
- 이미 생각한 후보와 뜻이 겹치지 않게 최대 10개를 만든다.
- 마음이란 사용자가 무엇을 바라는지, 왜 그렇게 하는지를 말한다. 행동을 적지 말고 마음을 적는다.
- 후보 하나는 한 문장으로 쓴다.
- 다른 말 없이 JSON 배열 하나만 출력한다.

예시 — 장면 1, 두 번째 사용자 줄을 «가 + 경고»로 채점할 때
