# 4일 일과 영상에서 세 가지 기억 방식 비교

직접 촬영한 공부 일과 이틀과 밤 일과 이틀을 순서대로 보여 주고, 로봇이 매초 어떤 도움을 선택하는지 비교했습니다. 앞선 날의 규칙을 **상태별로 저장**, **목록으로 저장**, **기억 없이 판단**하는 세 조건을 사용했습니다. 첫날에는 이전 기억이 없으므로, 아래 표는 기억을 이어받을 수 있는 둘째 날부터 보여 줍니다.

| 시험한 날 | 상태별 규칙 기억 | 규칙 목록 기억 | 기억 없음 |
|---|---:|---:|---:|
| 공부 일과 둘째 날 | 0.41 | 0.34 | 0.04 |
| 밤 일과 첫째 날 | 0.27 | 0.30 | 0.00 |
| 밤 일과 둘째 날 | 0.25 | 0.30 | 0.08 |

점수는 도움을 선택한 경우의 정확성과 필요한 도움을 찾아낸 비율을 함께 반영한 **행동 F1**입니다. 높을수록 좋습니다. 세 날 모두 기억을 쓴 조건이 높았습니다. 같은 첫날 입력을 다시 실행했을 때도 점수가 0.04와 0.15로 달라져, 상태별 기억과 목록 기억 중 어느 쪽이 더 좋은지는 이 결과만으로 정하기 어렵습니다.
