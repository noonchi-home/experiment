# 아침 관찰로 기억을 고친 뒤 다음 날 행동 판단하기

사용자가 기상하면 우유를 가져다주도록 설정한 로봇에 “식탁에 앉았을 때, 우유가 아직 없으면 가져다 달라”는 피드백을 줬습니다. 하루 관찰과 피드백을 읽고 기억을 고친 뒤, 기상·우유 없는 식탁·우유 있는 식탁의 세 장면에서 같은 사진을 다시 보여 줬습니다.

**기록된 결과.** 과거 아침 설정에서 관찰 시점 100개로 기억 갱신이 성공했고, 모델의 응답과 저장한 새 기억의 내용이 일치했습니다. 같은 사진 세 묶음에 대한 갱신 전후 판단이 확인됐습니다. 200개 시점을 한 번에 넣어 갱신하는 실험은 성공을 확인하지 못했습니다. 이 저장소에는 입력 텍스트와 검증 요약이 있습니다. [저장된 검증 수치](../../docs/검증결과_2026-10-25.json) · [무엇을 어떻게 대조했는지](../../docs/논문충실도_검증보고서.md)
