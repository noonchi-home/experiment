연구 방향 제안 · 구현 및 효과 검증 전

## PAM 복습 — 생활 순서를 기억하는 로봇

```text
생활 순서 기억 + 현재 상황
            ↓
     언제 · 무엇을 도울까?
            ↓
         도움 실행
            ↓
하루 기록 검토 → 다음 날 기억 갱신
```

**낮에는 실행 · 밤에는 자기반성**

자기반성 = 하루의 관찰·실행·피드백으로 도움 규칙을 수정하는 과정.

<small>기존 PAM도 생활 습관과 사용자 피드백을 반영한다.</small>

---

## 처음 아이디어 — 사람마다 개입 선호가 다르다

| **h · 도움 선호** | **w · 간섭 민감도** |
| :---: | :---: |
| 도움을 얼마나 반기는가? | 어떤 개입에 얼마나 민감한가? |
| 도움 자체에 대한 선호 | 가까운 접근 · 영역 침범 · 통제권 · 타이밍 |

> **“도움은 받고 싶지만, 가까이 다가오는 것은 싫다.”**

**개인별 선호를 반영 → 다음 날 도움을 유지 · 수정 · 제외**

---

## 한계 — 같은 반응, 여러 가능한 이유

### 관찰: 로봇이 가져다준 물건을 사용자가 옮겼다

| 가능한 해석 | 또 다른 가능한 해석 | 또 다른 가능한 해석 |
| :---: | :---: | :---: |
| 놓인 위치가 불편했다 | 작업 공간이 필요했다 | 사용하기 편한 위치로 옮겼다 |

```text
관찰한 행동              그 행동의 이유
“물건을 옮겼다”     ≠     “가까운 접근이 싫다”
```

**한 번의 반응 → 특정 성향으로 바로 연결하기 어렵다.**

---

## 한계 — 잘못 배운 특성도 다른 행동으로 퍼진다

```text
반응을 잘못 해석
       ↓
개인 특성을 잘못 학습
       ↓
처음 보는 도움에도 잘못 적용
       ↓
필요한 도움 제외 / 원치 않는 개입 반복
```

| 매번 이유를 물으면 | 관찰만으로 판단하면 |
| :---: | :---: |
| 사용자 응답 부담 증가 | 선호를 잘못 추정할 가능성 |

> **해결할 문제: 자주 묻지 않으면서, 개인 특성을 어떻게 추정할 것인가?**

---

## 연구 방향 — 여러 행동에서 공통 특성을 배우기

### 목표: 행동별 기억을 넘어, 새로운 도움에 적용

**처음 h(도움 선호)·w(간섭 민감도)의 목표는 유지하고, 반응 해석과 학습 근거를 보완한다.**

```text
서류 정리의 반응 + 공구 정리의 반응
                  ↓
           공통 특성 검토
       “작업 중 배치를 변경한다”
                  ↓
          개인별 선호 모델
   “이 특성을 얼마나 꺼리는가?”
                  ↓
       처음 보는 케이블 정리 평가
```

**예시 가설:** 작업 중 배치 변경을 꺼리는 근거가 충분하다면,
처음 보는 케이블 정리에도 그 특성을 적용할 수 있는가?

| 검토할 공통 특성의 예 | 개인별로 추정할 것 |
| --- | --- |
| 수고를 덜어줌 | 도움의 이득을 얼마나 중요하게 여기는가 |
| 작업 중 배치를 바꿈 | 현재 배치를 유지하려는 선호가 얼마나 강한가 |
| 주의를 끌거나 가까이 접근함 | 이런 개입을 얼마나 꺼리는가 |

<small>특성 목록과 추정 방법은 검증 대상. 관찰만으로 원인을 확정하지 않는다.</small>

---

## 연구 방향 — 선호 모델을 PAM의 자기반성에 적용

### 밤: 개인 특성을 반영해 다음 날 행동 선택

```text
하루의 행동 · 개입 · 반응 기록
                ↓
개인별 선호 모델 갱신
도움 선호 · 간섭 민감도 추정

                ↓ 적용

PAM의 도움 후보 → 특성 비교 → 유지 · 수정 · 제외
                                      ↓
                             다음 날 실행용 PAM
```

### 낮: 갱신된 규칙으로 선제적 도움 실행

**현재 상황 → 실행용 PAM → 도움 실행 → 반응 기록**

| 언어 모델의 역할 | 개인별 선호 모델의 역할 |
| --- | --- |
| 공통 특성과 가능한 해석 추출 | 기록을 바탕으로 특성별 중요도 추정 |
| 근거와 다른 설명을 함께 검토 | 새로운 도움의 적절성 판단에 적용 |

**기록이 부족한 특성은 미확인으로 유지 · 명시적 거절은 즉시 반영**

<small>기존 h(도움 선호)·w(간섭 민감도)의 관점은 유지한다. 반응 해석과 학습 규칙을 보완한다.</small>

## 검증 — 처음 보는 도움에서도 맞는가?

| 개인 특성을 배우는 기록 | 평가에만 사용하는 행동 |
| :---: | :---: |
| 서류 · 공구 정리의 반응 | 처음 보는 케이블 정리 |
| **학습에 사용** | **학습에서 제외** |

### 같은 기록 · 같은 행동 선택지로 비교

| 행동별 기억 | 언어 모델의 직접 판단 | 공통 특성 기반 개인 모델 |
| :---: | :---: | :---: |
| 이전 사례를 참고 | 기록과 프롬프트로 판단 | 개인 특성을 새 행동에 적용 |

**함께 측정할 것**

| 유지해야 하는 것 | 줄여야 하는 것 |
| :---: | :---: |
| 유용한 도움 | 원치 않는 개입 |
| 새로운 행동에 대한 판단 정확도 | 질문 · 사용자 수정 부담 |

> **덜 돕는 것만으로는 성공이 아니다.**

<small>실제 불편함은 사용자 평가로 확인한다. 평가용 응답은 학습 입력과 분리한다.</small>

## 연구 목표

> **사람의 특성을 추정하고,**
>
> **처음 보는 도움의 유지 · 수정 · 제외에 적용한다.**
>
> **사용자에게 자주 묻지 않으면서.**

아직 풀어야 할 것: **반응의 의미 구분 · 개인 특성 추정 · 새로운 행동에서의 검증**
