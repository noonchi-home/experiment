# GitHub 공개 전 논문 충실도 검증

검토일: 2026-10-25. 기준은 제공 PDF `2610.21211v1`과 저자 저장소 고정 버전 `656a63ef4607177dd3b404042086486531a573f4`입니다. 최신 원격 저장소 전체를 검토했다는 뜻은 아닙니다.

## 결론

**PAM의 핵심 판단·기억 갱신 구조를 반영한 상황 변경 구현이다. 원논문 전체 실험의 동일 조건 재현이나 성능 재현은 아니다.** 공개 명칭은 “PAM 기반 아침 식사 행동 판단 실험”으로 정리했습니다.

원문 프롬프트 7개와 입력·기억 구조의 핵심은 확인했습니다. 실제 모델은 여전히 우유가 이미 있는 장면에서 실패합니다. 이 실패를 수동 정답으로 바꾸거나 숨기지 않았습니다. 연구용 코드와 제한된 관찰 결과로 공개할 수 있으며, 일반적인 정확도 또는 논문 성능 달성을 주장할 근거는 없습니다.

## 발견한 문제와 조치

1. **현재 요구와 실행 시작점 불일치:** 발표는 식탁부터였으나 `scenarios/morning`의 초기 기억에는 과거 기상 조건이 남아 있었습니다. 과거 원본의 해시와 결과를 보존하고 현재 설정을 `scenarios/breakfast`로 분리했습니다. 현재 시작 상태는 `meal_preparation`이며 네 상태입니다. README와 새 실행 도구가 현재 설정을 가리킵니다.
2. **재현 범위 과장:** README의 “그대로 재현” 문구를 수정했습니다. 수동 기억, 합성 자료, 행동 목록·목적지, 제공자, 100개 시점, 로봇 실행 생략을 명시했습니다.
3. **실패가 있는 결과:** 현재 초기 기억으로 실제 재실행해 두 장면 중 하나만 맞았습니다. 실패를 그대로 공개 예시에 포함했습니다.
4. **공유 경로 문제:** 과거 준비 결과는 원래 컴퓨터 절대 경로를 포함합니다. 그대로 다른 컴퓨터에서 재사용할 수 있다고 주장하지 않습니다. 선택된 원본 사진·상대 경로 관찰 목록·기억 사본·실제 응답을 `experiments/breakfast_2026-10-25/`에 별도 구성하고 요청 재구성 도구를 추가했습니다.
5. **Git 줄바꿈과 해시:** `.gitattributes`로 증거 바이트의 자동 변환을 막고, 전사 프롬프트의 LF를 지정했습니다. 원문·응답 해시가 Git 줄바꿈 변환으로 깨지는 문제를 예방합니다.
6. **공개 대상 혼재:** 가상환경, 도구 바이너리, 전체 과거 자료, 개인 경로 로그와 저자 그림을 내장한 발표 파일을 기본 Git 제외 대상으로 분리했습니다. `.env.*`와 키 파일 확장자도 제외합니다. 외부 자료에 임의 라이선스를 붙이지 않았습니다.

## 공개 사본의 이동·Git 검사

공개 사본의 103개 파일을 임시 로컬 Git 저장소에 추가·커밋한 뒤 다른 경로로 clone했습니다. 103개 모두 원래 SHA-256과 일치했습니다. `.env`, `.env.local`, 키 파일, 생성 결과·기록·PDF·저자 사본·발표 파일 경로 여덟 종류의 Git 제외를 확인했습니다. 실제 프로젝트나 GitHub에는 커밋·업로드하지 않았습니다.

옮긴 사본에서 `verify_saved_evidence.py`로 요청과 원본 응답 일치를 다시 확인하고, `run_breakfast_checks.py`로 두 장면의 입력 준비도 성공했습니다. 이 이동 검사는 API 호출을 하지 않습니다. 공개 사본 104개 파일(목록 파일 포함) 스캔에서 알려진 비밀키 패턴과 Windows 사용자 절대 경로가 발견되지 않았습니다. 이후 추가된 이 검증 설명과 요약 JSON은 별도 최종 파일 목록에 반영합니다.

## 남아 있는 한계

- 현재 실제 검사: 두 조건, 각 1회, 단일 합성 집. 독립적인 일반화 시험·반복 통계 없음.
- 우유 위치를 잘못 서술한 응답이 관찰되지만, 내부 원인을 시각 모델이나 기억 편향 중 하나로 확정할 수 없음.
- 합성 관찰과 행동 요약, 초기 습관은 사람이 설계. 자율 습관 발견의 증거가 아님.
- 첫날 관찰에서 기억 생성, 현재 네 상태 기억의 새로운 자기반성, 식기 정리 전체 흐름은 이번 실제 재실행에서 검증하지 않음.
- 장기 상태 추적기를 별도 추가하지 않음. 짧은 사진 창에 식사 종료·외출 증거가 부족하면 전체 기억만으로 그 사실을 확정할 수 있다고 보장하지 않음.
- OpenRouter의 모델 내부 설정은 논문의 vLLM 환경과 동일하다고 입증하지 않음. 200개 시점의 실제 성공·실시간 1 Hz·로봇 실행 없음.
- 원본 PDF 없이 전체 테스트를 돌리면 원문 대조가 실패합니다. 이것을 건너뛰어 완전한 원문 검증 성공으로 표시하지 않습니다.

이 보고서의 통과는 **입력 구성·원문 보존·실행 증거 일관성**에 대한 것입니다. 모델이 모든 장면을 올바르게 판단한다는 인증이 아닙니다.
