# 실제 Qwen 응답과 두 식탁 장면

2026-10-25에 현재 식탁 시작 초기 기억으로 OpenRouter의 Qwen3.5-27B / Alibaba를 두 번 호출한 기록입니다. 사람이 작성한 초기 기억을 사용했으며 이 실행에서는 자기반성을 호출하지 않았습니다.

| 조건 | 기대 | 실제 | 결과 |
|---|---|---|---|
| 식탁 착석, 우유 없음 | 우유 가져오기 | 우유 가져오기 | 성공 |
| 식탁 착석, 우유 있음 | 대기 | 우유 가져오기 | 실패 |

각 관찰 목록에는 0·2·4·6·8초의 서로 다른 두 카메라 원본이 있습니다. `scenario/`는 이 실행에 사용한 기억과 설정의 사본입니다. `result.json`, `api_response.raw.json`, `request_record.json`은 실제 저장 파일을 바이트 그대로 복사했습니다. `evidence.json`에는 복사본 해시와 입력 사진 해시를 기록했습니다. 원래 컴퓨터의 절대 경로가 든 준비 입력·전체 로그는 배포 예시에서 제외했습니다.

사진 생성: 이 프로젝트의 Blender 4.2 합성 장면. 실제 촬영 자료가 아닙니다. 원래 합성 관찰의 선택된 시점만 포함했으므로 하루말 200장 반성용 자료로 사용할 수 없습니다. 기대 행동은 별도 증거 파일에 있고 모델 입력 관찰 목록에는 없습니다.

현재 초기 기억으로 입력 준비만 하기(과금 없음):

```powershell
python tools/run_breakfast_checks.py --dataset examples/breakfast_2026-10-25 --output artifacts/my_breakfast_prepared
```

실제 모델을 다시 호출하려면 환경변수 `OPENROUTER_API_KEY`를 설정하고 새 출력 경로와 `--execute`를 사용합니다. 최대 두 번의 유료 API 호출이며 출력은 달라질 수 있습니다. 과거와 정확히 같은 기억을 준비하려면 `scenario/scenario.json`과 개별 관찰 목록을 `python -m pam prepare-predictor`에 명시하십시오.

이 결과는 한 합성 환경의 조건별 1회 실행이며 일반 정확도나 논문 성능 재현을 입증하지 않습니다. 두 호출의 보고 비용 합계는 $0.001271790입니다.
